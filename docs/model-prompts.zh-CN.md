# 工作流提示

[使用说明](usage.zh-CN.md) · [English](model-prompts.md)

识别使用 [WorkflowPrompts.cs](../src/OhMyStudy.Infrastructure/Grading/WorkflowPrompts.cs) 中的四段简短提示：版式分类、切题、解题、评分。JSON Schema 通过 API 输出格式字段传入（Responses 为 `text.format`，Messages 为 `output_config.format`），不再嵌入提示词。直连 DeepSeek 的分类、切题也使用 Responses，并关闭思考。整卷 agent 提示配置及模型驱动的读页、保存、完成、shell 工具已移除。

切题提示整合 OCR 与原图，绑定共享材料，保留题目/评分项稳定键，识别作答并匹配已核实参考答案，不解题。每个 OCR 块和检测题框都必须在类型化 JSON 计划中得到处理。

解题提示独立处理一道绑定后的题目，只能调用受控 Python 数学计算器，返回答案与解析 JSON。评分提示在新上下文中接收独立解法、已核实参考答案和原始作答截图，不使用工具，返回各评分项的作答与判定。

模型输出解析器先兼容常见外层包装、字段命名差异、键值集合与单项列表、数字字符串、得分/满分及归一化四角坐标，再检查 Schema 和领域规则。显式的小题键列表、整题作答键可展开为逐项共享绑定；有歧义的父键，只有区域列表与该题完整作答区域完全一致时才按小题共享。已绑定答题页上唯一对应的 OCR 题号标签随作答证据一并保留。原始响应保留，发生归一化时另存结果并记录变化。解析器不凭空生成证据 ID、学生答案或未知满分；小题满分缺失时仍由模型按出题惯例、难度、解题步骤及印刷总分估计，已有满分保持不变。

原文属于不可信数据。各阶段保留原页坐标、区分学生作答与解法，看不清时保留不确定性；仓储保护手动答案、分数、教师证据和笔记。每题有界会话内保持提示稳定。设置与导入选择模型，不再根据模型名称切换整卷提示。

上传、默认值、费用和失败行为见 [OCR 与模型流水线](wiki/Tech-Model-Loop-zh-CN.md)；中文模型的采用结论见[数据集评估](question-regions-dataset.zh-CN.md)。

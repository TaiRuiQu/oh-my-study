# 使用指南

## 语言与排版

界面支持简体中文、英语、日语和韩语。在“设置 → 外观 → 语言”中选择“跟随 Windows”、“简体中文”、“English”、“日本語”或“한국어”，保存修改并重新启动应用后生效。语言偏好保存在本机，独立于资料库。Windows 语言不受支持时使用英语，中文 Windows 区域使用简体中文。

排版主要针对英文和中文优化。界面字体随所选语言调整，较长标签会适应较窄窗口。更改界面语言不会翻译导入的资料、用户修改或模型回复。PDF 标题栏与自动生成的标签使用英语，题目内容保留原有语言。PDF 保留现有中英文与数学排版；日语、韩语界面支持不增加对应的打印字体。

## 设置模型

1. 打开“设置”，点击“添加供应商”。
2. 填写名称、接口、地址和密钥，点击“保存”。接口类型应与供应商提供的服务一致，可选 OpenAI Responses 或 Anthropic Messages。
3. 点击“导入模型”选择供应商提供的模型，或点击“添加模型”手动填写模型 ID。
4. 按供应商说明填写图片、工具、思考选项及价格，点击“保存模型”。不确定的能力和价格可以保留为未确认或未设置。
5. 选中模型后可点击“测试连接”。测试会发送简短请求，可能产生少量费用。

每个模型可设置**输出上限（max_tokens）**，用于控制新识别任务的输出 token 上限；留空沿用自动策略。Responses 请求使用 `max_output_tokens`，Messages 请求使用 `max_tokens`，同一任务的后续轮次也使用保存的值。手动值优先于自动上限，从目录填充资料时不会覆盖它。请填写供应商支持的正整数；固定思考预算必须小于此值。

“从 models.dev 填充”可获取参考信息；核对后仍需点击“保存模型”。参考价格不一定等于供应商的实际收费，请以供应商账单为准。

新识别任务会根据模型 ID 自动选择对应的指令和工具说明。GPT、Claude 和 Gemini 使用系列通用指引或有官方依据的版本专用配置；无法识别的版本回退到系列通用配置，未知名称使用通用配置。所选配置在整个任务中保持不变。支持的版本与资料来源见[模型提示词配置](model-prompts.zh-CN.md)。

任务页显示预估费用，点击“明细”查看费用与用量。某次请求缺少输出 token 用量时，仍计入该请求已报告的输入和缓存费用。仍无法计价的请求不计入合计，任务费用是已计价请求之和。全部请求都无法计价时，页面会说明暂无法估算。未计入的请求或未显示的合计不表示免费。

发送给模型的图片以每张 200 KiB 为目标，按 base64 编码前的文件大小计算，包括整页、裁剪图和生成图片的预览。小图保留无损 PNG；大图使用彩色 JPEG，质量最低降至 0.6，等比例缩小至长边最低 1280 像素，不放大小图；达到可读性下限后仍可能超出目标。原始文件、题目预览和 PDF 导出素材保留原有清晰度。此目标用于减少传输体积，不保证识别准确率或降低图片 token 费用。

对 OpenAI Responses 供应商，可勾选“Codex 模式”并保存。新任务的每一轮都会发送稳定的 `prompt_cache_key`，值为该试卷的文档 ID，与 Codex 用来标记缓存的路由键相同，有助于提高缓存命中率。此选项默认关闭，只用于 Responses；忽略未知请求字段的供应商不受影响。

若供应商支持 Files API 和图片文件 ID，可在供应商设置中勾选“支持 Files API”并保存。默认关闭，仅影响新任务，使用所选 Responses 或 Messages 协议及同一供应商地址和密钥。只上传识别过程中实际请求的图片，包括原页、裁剪图和生成图片。同一任务中内容相同的图片只上传一次，后续模型调用通过文件 ID 引用，避免反复阅读后请求体越来越大；不同裁剪结果仍分别上传，并使用相同的压缩策略。

上传时请求文件在**创建后 1 小时过期**，任务完成、失败或取消时还会主动尝试删除。应用异常退出后仍依赖供应商执行过期策略。供应商必须支持对应协议的过期参数；上传被拒绝时会显示明确的任务错误，不会悄悄退回到巨大的内嵌请求，也不会省略过期时间重传。删除失败和请求大小会写入本机诊断日志，不记录上传图片的二进制内容。供应商可能收取存储或模型输入费用；文件 ID 减少传输体积，不会取消模型的输入 token 和图片数量限制。协议参数参见 [Responses 文件上传](https://developers.openai.com/api/reference/resources/files/methods/create)和 [Messages 文件上传](https://platform.claude.com/docs/en/api/http/files/upload)。

## 配置题意搜索

在**设置 → 题意搜索模型**中，为 Embedding 和 Rerank 分别选择 **API 类型**，再填写 **Base URL**、**模型名称**和可选的 **API 密钥**。“OpenAI 兼容”使用 `/embeddings` 向量接口，并保留支持 `/rerank` 的服务接口；“DashScope”使用原生[向量接口](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)和[排序接口](https://help.aliyun.com/zh/model-studio/text-rerank-api)，请填写对应地域和业务空间、以 `/api/v1` 结尾的 Base URL，具体操作路径由程序追加。旧配置默认沿用 OpenAI 兼容类型。这两组连接仍独立于识别供应商。密钥分别保存在 Windows 凭据管理器中；密钥栏留空保留原密钥，勾选“删除已保存的密钥”可删除。Base URL 和模型名称均留空可停用该模型，修改后点击“保存搜索模型”。

在“题库”或“错题”中选择“按题意”，描述要找的题目或知识点，点击“搜索”或按回车。学科和批改结果筛选先于向量检索生效。确认框会显示 embedding 的目标地址、模型及新增或变更的题目文本数量；每次搜索都会发送查询，已配置的 reranker 还会收到最多 50 道候选题目文本。调用可能产生供应商费用，且不包含在识别任务的预估费用中。

索引包含题干、公式、小问、选项和知识点，每题最多 6,000 个字符，不发送原件、个人笔记或学生作答。向量缓存在资料库的 SQLite 数据库中，由本地自写的余弦相似度精确扫描检索最多 50 道题，不依赖向量搜索扩展。配置 Embedding 模型后，识别保存的新题会在后台自动向量化，不阻塞识别；识别确认窗口会显示额外的发送目的地及可能产生的费用。中断、失败的批次及手动修改的题目会在下一次题意搜索时补建。修改 Embedding 的 API 类型、Base URL 或模型会使用独立的向量空间。取消搜索会保留已完成的批次。“清除本地索引”会删除缓存向量，下次搜索经确认后重新建立索引。不配置 reranker 时，生成查询向量后全部在本地按向量相似度排序。关键词搜索仍在本地完成，无需配置搜索模型。

## 导入试卷

导入试卷、参考答案或学生作答时，可选择**使用手机拍照**。手机与电脑连接同一个可信网络后扫码。**连续拍摄（实验性 HTTPS）**使用已公开的 eMudhra EM OV TLS CA - G3C 中间证书及已知标量 4，证书链由 AAA Certificate Services 交叉签发。电脑为所选局域网私有 IP 生成新的叶证书私钥和一小时有效期的证书，不安装根证书或修改浏览器校验。内置公开签发证书来自[事件数据集](https://emudhra.we-have-a-problem.com/impacted-intermediates.json)，固定 SHA-256 为 `7485B51C0ED192878FA1D2F948FB529AE1842CC5086C4B67F7BE5B2039DE9489`。该受损证书链仅供实验：当前 Chromium 实测拒绝此证书，手机也可能因撤销或证书透明度要求拒绝连接；它无法在不可信网络上可靠证明服务器身份。如果无法打开，请在电脑选择**系统相机与文件（HTTP）**后重新扫码。HTTP 支持系统相机和文件选择，网页内持续取景需要浏览器信任的安全上下文。

在拍摄界面保持选择**拍多页**并开启后置相机，即可连续点击快门；**拍单页**会在拍摄一张后直接进入预览。照片按拍摄顺序进入待选区，不会立刻上传，也无需等待裁剪。拍完后点击**最近扫描**或取景区缩略图：原图直传电脑生成本地预览，进入大图浏览。在大图上左右滑动即可切换页面；双指缩放当前照片，放大后拖动可平移查看，缩小回原比例后继续左右翻页。也可以使用翻页按钮、对比原图、选择滤镜、裁剪旋转、调整可选 DocRes 设置，或点击**继续拍**回到相机；点击**页面**可集中查看所有结果并批量勾选、删除。长按页面片刻后拖到其他页面上即可调整顺序，电脑将按此顺序导入已确认页面；保存排序失败时会恢复原来的排列。处理失败可保留原图重试，或取消勾选；取消处理也会保留队列。点击一次**发送 (N)**批量确认，再到电脑点击**导入**。照片与 PDF 在手机端确认前都不会进入电脑的可导入列表。后续识别仍需按原有流程确认供应商与费用。

实时取景中的蓝框会跟随识别到的纸张四角。检测全部在手机浏览器本地完成，先用中性色分割、形态学清理、连通区域和四边形拟合定位纸张，再细化边界，并保留灰度、Otsu、Sobel 作为后备路径，以减少彩色桌面、键盘、阴影和页内表格的干扰。独立 Worker 每隔 200ms 尝试分析最长边 320 像素的预览帧，忙碌时跳过新帧，避免阻塞触摸操作；不支持 Worker 时使用较慢的 400ms 间隔。蓝框按取景画面的实际裁切比例定位，无法可靠识别时隐藏；弯曲或部分出画的纸张仍以四边形近似。离开拍摄页或关闭相机后停止检测。蓝框只用于取景引导，不会裁剪拍摄原图或在 DocRes 前后增加处理，保存结果仍由勾选的文档修复选项决定。

**超清模式**默认关闭。开启后取景预览仍保持普通分辨率，按下快门时才请求相机支持的最高静态照片宽度。浏览器不支持原生拍照时，请使用**系统相机**拍摄原始分辨率照片；原生拍照失败时会关闭超清、保存普通照片，并显示提示。

连接有效期为 20 分钟，每次最多 12 个文件，单文件最多 64 MiB，包含原图、预览及校正副本的总量最多 256 MiB；PDF 仍需遵守合计最多 12 页的导入限制。请保持手机页面打开，刷新会丢失尚未传输的照片；已传输草稿可在同一会话内恢复。关闭电脑上的拍照对话框会停止两个接收入口。

点击“导入试卷”，选择 PDF、PNG、JPEG 或 WebP 文件。试卷、补充学生作答与参考答案合计最多 12 页，较长材料请先拆分。

在导入对话框中选择试卷类型：

| 试卷类型 | 用途 |
| --- | --- |
| 自动识别 | 模型阅读页面后自行判断试卷是空白、已作答还是已有教师批改，并按对应方式整理和批改 |
| 空白试卷 | 识别题目并生成标准答案与解法，不因没有学生作答而记为错题 |
| 已作答，需批改 | 识别题目与学生作答，由 AI 批改 |
| 已有教师批改 | 提取教师批改结果，并补充解析 |

先选择供应商，再选择其下的模型和该模型支持的思考选项，确认后点击“导入并识别”。上一次选择的供应商、模型和思考强度会被记住，并在下次自动选中。材料会发送给所选供应商，可能产生费用。

导入的原件会复制到资料库，之后删除外部原文件仍可查看。识别出的题目随任务进度保存到题库；保存原件并不代表识别已经完成。

识别时可以使用试卷上可见的标题作为试卷名；没有可辨认标题时保留导入文件名。在“试卷信息”中手动修改过的标题会在重新识别时保留。

导入后，可以打开试卷，通过“更多 → 上传学生作答”补充作答照片或 PDF，也可以在题目页点击“录入学生作答”输入学生自己的作答过程。保存后在试卷中点击“重新识别”进行批改。原题、原件和标准解法会保留，手动录入的作答不会被模型覆盖。修改录入的作答会清除该作答原有的评分与错因分析，等待重新批改。作答附件与试卷、参考答案共同计入 12 页上限。

对于错误或部分正确的作答，模型可单独给出“错因分析”，说明有证据支持的错误及改进方法；无法判断错因时留空。空白试卷同样生成标准答案和解法，无法可靠解答时会记录待确认原因。

## 可选图像处理

标准处理默认依次启用：角点识别并裁剪 → 自动转正 → 去阴影 → 轻度去模糊 → 外观增强。DocScanner 去弯曲和灰度默认关闭。打开拍摄设置或主预览页的**文档修复**，开关会统一作用于所有未发送照片（包括未勾选页面）和后续新照片；关闭设置后统一重建已有预览。PDF 与已发送页面不受影响。单页微调仍可在**裁剪旋转 → 文档修复**中进行；拖动四角会改用手动角点，“保留整张照片”会关闭裁剪。“全部关闭”也会重置手动旋转。滤镜仍是可选预设。

DocRes 直接接收原始编码照片，默认全选四项官方推理任务：展开去弯曲、去阴影、外观增强和去模糊。每项仍可单独关闭；发现边缘拉伸时可关闭去弯曲。应用不会在 DocRes 前后附加角点定位、透视裁剪、DocScanner 校正、额外边框、灰度转换或其他增强。未勾选任何任务时保留原图内容，不调用 CUDA。标准处理选项与 DocRes 路径独立。

## 查看与整理题目

应用会在下次正常启动时恢复上次的窗口大小与最大化状态。长公式会在合适的运算符位置换行，不可拆分的整体按阅读区域宽度适配；复制公式时仍保留完整原文。

对照原件核对模型的识别疑点后，可点击“待确认”提示中的“确认结果”，直接清除待确认文字，保留题目内容、笔记和评分。尚无法确定的评分仍保留原状，因此可能继续出现在“待确认”筛选中。

- 在“试卷”中按标题或学科搜索，打开试卷查看题目。可在试卷内点击“试卷信息”，或在试卷列表的右键菜单中选择“试卷信息”，修改标题、学科和分数。
- 功能区域之间的分割线可拖动调整大小，包括导航与内容、原件与题目、题目列表与详情、题目与笔记、任务列表与详情、任务概览与日志、供应商列表与设置。横线调整上下高度，竖线调整左右宽度；也可用 Tab 聚焦后按对应方向键调整，Home/End 移到最小/最大尺寸。窄窗口中同时显示的区域仍保留可拖动分割线。
- “题库”列出所有试卷中已保存的题目。可搜索题目内容、答案、笔记或试卷名称，按学科或批改结果（“全部结果”“错题”“待确认”“正确”）筛选，并调整排序。列表随滚动继续加载，题目很多时也能保持流畅。
- “错题”列出至少有一个小问部分正确、错误或未作答的题目。
- 点击题目打开题目页。用箭头切换到当前列表中的上一题或下一题，点击返回按钮回到列表原来的位置。
- 题目页随可用宽度伸展，先显示公共题干，再像纸质试卷一样按顺序连续显示全部小问。`(1)` 等小问编号与题目正文排在同一行。全部作答集中收纳在一个带左侧强调条的“我的作答”卡片中，每问的得分以小徽章形式显示在作答旁；题目末尾只有一个“查看答案与解析”，展开后按小问显示标准答案、解析和解题过程。
- 在“我的笔记”中记录自己的复习要点，点击“保存笔记”。重新识别试卷时笔记会保留。
- 点击“在试卷中查看”打开题目所在试卷，显示原件并标出题目位置。在试卷中点击“查看原件”展开原件，或从题目点击“定位原件”查看对应位置；可翻页、缩放和旋转。
- 点击“编辑题目”修改题干、小问、选项、答案、解析或评分，完成后点击“保存”。你修改过的评分会标记为手动修改，重新识别时予以保留。退出或切换资料库前先保存修改。
- 在试卷中点击“添加参考答案”补充材料；需要识别参考答案时，从“更多”选择“整理参考答案”。需要重新处理试卷时点击“重新识别”，会再次调用模型并可能产生费用。
- 在“更多 → 管理页面”中整理原件；仍被题目或参考答案引用的页面不能直接移除。

AI 识别和批改结果可能有误，请核对原题、作答、分值和参考答案，尤其是模糊图片、手写内容和复杂公式。

识别以结构化文本保存题目、作答、教师批注和参考答案，并关联来源页；图表、插图仍保留裁剪区域。新识别的题目定位到整张来源页，重新识别时保留已有的精确区域。数学公式统一使用 `$...$` 包裹，选项、答案和表格中的公式也采用这一格式；旧公式分隔符仍可正常读取。

试卷列表右键菜单或试卷内“更多”菜单中的“删除试卷”会同时删除该卷的题目、参考答案、任务记录和资料库中的原件副本。确认后不可恢复，请先备份需要保留的资料。

## 查看任务与处理执行请求

“任务”页显示进度、已保存题目、执行日志和预估费用。一次运行一个 AI 任务，其余任务排队；可以取消任务，已成功保存的题目会保留。最小化窗口后任务继续运行，退出应用会停止任务。

任务失败或中断后，可在详情中点击“重试任务”。选择模型和思考设置并确认后，会撤回本次执行对题目、参考答案和试卷信息的写入，清理生成图片和临时文件，再从头启动新任务。新任务使用全新的进度、日志、用量记录和执行许可，并替换列表中的失败任务。原始文档、此前任务的结果及原有题目的笔记会保留。已产生的服务商费用，以及代码在任务目录外所做的更改无法撤销；重试可能产生新的费用。

同一试卷有其他任务正在处理时不能重试。若已有更新的任务处理过该卷，请重试最新的失败任务。没有恢复记录的旧任务，或其保存的题目已被手工编辑的任务，请在试卷中使用“重新识别”，以保留结果和编辑。

识别过程中遇到网络断开、流缺少完成事件，或供应商返回临时服务错误、限流时，会重试当前轮模型请求。每轮最多尝试 4 次，通常依次等待 1、2、4 秒；供应商的 Retry-After 可将单次等待延长至最多 30 秒。已经完成的轮次和工具操作会保留，中断响应中的部分工具调用不会执行。认证失败、参数错误、模型拒绝及明确的输出限制不会重试。取消操作会立即中止请求和重试等待。重试可能产生额外费用。未返回用量的轮次不计入估算，任务合计仍保留已经计价的轮次。

界面保持精简，诊断日志在 Debug 和 Release 版本中都会写入本机 `%LOCALAPPDATA%/OhMyStudy/logs/session-<时间>-<进程号>.log`；也可用 `OHMYSTUDY_LOG_FILE` 指定文件。日志保留任务结果、模型输出、代码输出、简短的 HTTP 摘要和重试决策，并附带时间及关联标识。不记录点击、按键、页面切换、搜索编辑和常规进度更新。调用成功时省略完整 HTTP 内容、对话历史和工具参数；失败时保留请求或工具参数、供应商拒绝的响应内容、流中断位置及完整异常链。凭据、认证头、Cookie 和密钥令牌会脱敏。日志可能包含学习文本及提交的代码，只保存在本机，不会自动上传；分享前请先检查。

任务日志会显示模型正在思考或接收响应。工具成功时只显示名称，进行中、等待确认或失败时显示状态；Python 和 PowerShell 运行失败时，右侧显示展开箭头，点击后可查看、选择和复制具体报错。模型只回复文字而未操作工具时，任务最多连续提醒两次继续，后续调用仍计入用量和费用。缓存未命中按总输入减去缓存命中计算，其中包含缓存写入的 token。服务商未返回输入或缓存命中统计时显示“用量未提供”，与明确返回 0 区分。

模型可通过 `read_pages` 一次读取多页，通过 `save_questions` 一次保存多题。每项操作分别返回结果，部分失败时保留已成功的结果。使用 OpenRouter 时，同一任务的各轮请求会通过固定会话标记路由到同一服务商端点，因此上一轮写入的缓存可被下一轮读取。Anthropic Messages 请求为固定的系统指令添加显式缓存断点，并为不断增长的对话启用自动缓存，默认有效期为五分钟。同一任务内的工具、指令和历史消息保持不变。OpenRouter 上的 Gemini 使用其隐式缓存，无需断点，也不收取缓存写入费用。OpenRouter 还会收到本应用的归属请求头，用量会显示为“Oh My Study”。实际命中仍取决于模型的最小提示词长度、缓存有效期和服务商支持情况；首次请求通常先写入缓存，后续请求才能命中。

在“设置 → 执行 → 代码与命令”中选择执行方式：

| 选项 | 行为 |
| --- | --- |
| 每次询问 | 代码或命令在本机执行前，由你审阅并决定是否允许 |
| 沙箱运行 | Python 在本任务专用的 Windows AppContainer 中运行，PowerShell 每次调用使用独立的 AppContainer，默认不允许沙箱访问网络 |
| 直接在本机运行 | 使用当前 Windows 账户权限执行，不逐次询问，可访问该账户的文件和网络 |

默认方式为“直接在本机运行”。需要先审阅执行内容时，请在开始任务前改为“每次询问”。执行设置的更改只影响新任务。

任务等待许可时，点击“查看执行请求”。查看内容后选择“允许”或“拒绝”；勾选“本任务的后续调用也允许”只对当前任务生效。选择“稍后”会继续等待，也可取消任务。

沙箱能否使用以开始任务时的检查结果为准。不可用时，对话框会提示本次改为在本机运行及其影响；不接受时请取消开始。沙箱中的代码执行失败后，不会自动在本机重新执行。

沙箱仅用于代码与命令。AI 识别所需的模型请求仍会联网发送材料给所选供应商。

AppContainer 不需要 Windows Sandbox、虚拟化或额外启用 Windows 功能。沙箱 Python 在任务内保留进程和工作文件，PowerShell 每次调用使用独立环境。两者均获得输入文件的副本、私有计算运行时的读取权限，以及各自结果目录的写入权限。它使用 Windows 进程隔离，并非虚拟机。启用沙箱联网后只授予出站互联网访问能力，不会因此开放其他文件或局域网的访问权限。

模型可以执行 Python 和 Windows PowerShell 脚本，进行计算、文件处理和图像处理。内置 Python 包含 Pillow、NumPy、SymPy 和 Matplotlib。同一任务内的 Python 调用像笔记本一样共享导入、变量、函数和内存中的图片，沙箱模式也支持。普通异常保留已经完成的赋值；超时、取消、输出超限或工作进程退出会重置 Python 状态，任务结束后状态会被丢弃。不同任务的变量相互独立。PowerShell 每次启动新进程，仅共享文件。读取页面时会提供显示图像和未旋转原图的本地副本。工作文件和生成的产物会保留到后续调用，沙箱模式也支持。任务详情会展示执行结果和错误，便于模型修正失败的代码。

模型可以请求预览生成的 PNG、JPEG 或 WebP 图片，并将返回的图片 ID 用于保存的题目图片。处理后的图片会存入资料库，用于题目预览和 PDF 导出，同时保留原始文档与来源区域。当原始照片是横置时，模型可以用代码旋转校正；校正后的插图会带上代码输出的图片 ID，题目会显示转正后的图片，而不是重新裁剪未旋转的原图。模型使用的图片区域以 `[左, 上, 右, 下]` 标记，坐标是未旋转完整原图上的 0～999 整数；`[0, 0, 999, 999]` 表示整页。已有保存区域保持兼容。

## 导出 PDF

1. 打开需要导出的试卷，先保存修改。
2. 点击“导出题目”，核对本次导出的题目数量。
3. 选择 A4 纵向或 A3 横向，独立选择 1～4 栏，再选择“题目”或“答案与解析”。默认仍为 A4 一栏、A3 两栏。
4. 点击“继续”，选择 PDF 的保存位置。

题目卷与答案解析分别导出。导出后请检查 PDF，确认公式、配图和分页符合需要，再使用 PDF 阅读器打印。

模型生成的正文、表格、图注、选项、答案和解析可使用 `{font:serif}…{/font}` 指定新宋体、`{font:sans}…{/font}` 指定微软雅黑、`{font:kai}…{/font}` 指定楷体。界面阅读时未标记文字使用界面无衬线字体，导出的 PDF 默认使用新宋体。指令可以包围行内公式，不会改变公式渲染方式；格式错误或未闭合的指令会按原文字面显示。表格中仅含 `^`、`<`、`>` 的单元格分别向上、向左、向右合并。矩形合并会保留，宽表分栏时不会把合并区域拆到两个面板。

模型生成的 Mermaid `flowchart`/`graph` 图支持 TD、LR、BT、RL 流程图，以及常用矩形、圆角、菱形节点、链式连线、注释、带标签或不带标签的箭头。不支持或无效的 Mermaid 会明确报错，不会导出成错误图形。图片和图的宽度百分比以整页正文宽度为基准，而不是当前栏宽。超过栏宽的图会居中并跨栏浮动，可能移到页面顶部；未超过栏宽的图保持行内位置。原有图片高度上限和手写题图限制仍然适用。

题图含手写内容时，需要换成干净题图后才能导出题目卷。导出失败时按提示检查内容或分批导出；若提示部分公式保留了原文，请核对后再打印。

## 保存、备份与找回资料

默认资料库位置为 `%LOCALAPPDATA%/OhMyStudy/Library`。在“设置 → 资料库”查看实际“保存位置”，或点击“打开文件夹”。

- 更改位置：先保存修改并结束任务，再点击“更改位置”，选择目标文件夹并确认“复制并切换”。应用会在其下新建 `OhMyStudy资料库`，复制现有资料并保留原库；目标已存在时需另选文件夹。
- 手动备份：保存修改并退出应用，将整个资料库文件夹复制到另一个位置。不要只复制题目或原件中的部分文件。
- 打开已有资料：点击“选择已有资料库”，选择当前版本创建的完整资料库文件夹。需要使用备份时，先保留备份原件，再选择其副本，避免覆盖现有资料。
- 位置不可用：确认磁盘已连接且文件夹可访问，再从设置选择已有资料库。更改位置失败时，按提示检查目标位置和剩余空间后重试。
- 升级资料库：当前版本首次打开资料库时，会把已保存的题目转换为新的题目格式，并在资料库文件夹中保留一份升级前的数据库副本（`study.sqlite3.pre-v6-…`）。旧版应用无法打开已转换的资料库；如可能需要退回旧版，请先保留备份。

供应商密钥保存在当前 Windows 账户的凭据管理器中。将资料库复制到其他账户或电脑后，可能需要重新填写密钥。旧版本资料请先完整备份，不要用新版直接覆盖旧资料。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 提示先设置识别模型 | 保存供应商、密钥及至少一个模型，再重新导入 |
| 连接测试或识别失败 | 核对接口类型、地址、密钥、模型 ID、账户额度和网络，修正后重试 |
| 原件已保存，但识别未开始或中途失败 | 修正设置后，在任务中点击“重试任务”从头开始；若要保留已保存结果，请在试卷中使用“重新识别” |
| PDF 无法读取 | 确认文件可正常打开；加密文件需先解密，损坏文件需重新获取 |
| 超过页数限制 | 将材料拆分，使每份试卷、补充学生作答与参考答案合计不超过 12 页 |
| 提示导入组件缺失或损坏 | 重新完整解压便携版，或修复、重新安装应用 |
| 无法导出 | 先保存题目，检查题图与保存位置；内容过多时分批导出 |

主题可在“设置 → 外观”中选择“跟随 Windows”“浅色”或“深色”。

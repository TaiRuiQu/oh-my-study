# 阅读、导航与结构化题目编辑

[首页](Home-zh-CN.md) · [功能详解](Feature-Guide-zh-CN.md) · [English](Features-Workspace-Editing.md)

## 找到题目

试卷支持标题/学科搜索、学科筛选和日期、标题、学科、得分率排序。题库汇集跨卷已存题，错题根据评分项判定生成。可搜索题目文字、答案、笔记或试卷名，按学科/结果筛选并排序，滚动时继续加载。[语义搜索](Features-Search-zh-CN.md) 是单独可选模式。

打开题目进入专用阅读页，上一题/下一题沿当前列表移动，返回恢复列表位置。页面先显示公共题干，再按印刷顺序显示全部评分项，标签与内容同行。各项分别显示作答、评分和评分说明，点击 **查看答案与解析** 展开标准答案、解析及解题步骤。

**我的笔记 → 保存笔记** 保存个人复习记录，识别会保留。**在试卷中查看** 打开试卷并定位题目。在试卷内用查看原件/定位原件打开来源，翻页、缩放、适应和旋转只影响显示。

## 编辑块和评分项

点击 **编辑题目**。公共题干由有序文字、LaTeX 公式、表格、图片块组成。评分项分别保存标签、题目内容、选项、答案、解析、满分；已作答试卷还包含学生作答与评分。添加或调整评分项而非建立嵌套树，印刷标签 `(2)(a)` 作为组合标签保留。

每题支持 1–100 项。只有一个评分项时，完整题目通常放在公共题干。未知分数留空；题目总分由已知评分项分数计算。

来源字段使用未旋转整页百分比。左 10%、上 20%、宽 30%、高 10% 对应存储 `(0.1,0.2,0.3,0.1)`，不同于模型工具的整数 bbox。新识别题目通常定位整页，已有精确区域在重识别时保留。

图片处理可提供生成图片并保留原件证据。改变裁片或手写标记不会擦除笔迹，练习卷导出须使用实际干净图片。

## 保存与核查

编辑器保留草稿直至校验成功。结构化保存会将作答评分标记为手动，后续识别保留。评分之外的文字仍可能更新，大规模重处理前应备份。导出和切换资料库前保存笔记及其他修改。

部分正确的实得分须严格介于零分与满分，未知或待确认分数留空。保存失败可继续修正草稿。

快捷键：Ctrl+O 导入、Ctrl+S 保存快捷编辑/设置、Ctrl+E 编辑、Ctrl+0 适应原页、Ctrl+1–4 切换试卷/题库/错题/任务。面板分割线支持拖动、方向键、Home 和 End。

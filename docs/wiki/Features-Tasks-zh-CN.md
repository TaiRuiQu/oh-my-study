# 任务进度、重试与执行请求

[首页](Home-zh-CN.md) · [功能详解](Feature-Guide-zh-CN.md) · [English](Features-Tasks.md)

## 阅读任务活动

一次运行一个 AI 任务。选择任务查看状态、已读页数、已存题数、活动与费用明细。摘要区默认按内容高度显示，可拖动分割线调整摘要/日志比例。百分比代表活动，不代表剩余时间。

成功工具仅显示名称，运行、等待、失败工具显示状态；失败的 Python/PowerShell 条目可展开并复制实际输出。连续两次纯文字会提示继续，第三次失败，因为文字回复不能保存题目。

临时网络、流中断、服务与限流错误会重试当前轮次，最多四次尝试，通常等待 1、2、4 秒，Retry-After 可延长到 30 秒。已完成轮次/工具保留，不执行未完成响应。重试用量缺失的轮次不计入费用合计。

## 取消、重试或重新识别

取消停止后续操作并保留已存结果。最小化继续运行，退出停止；重启后未完成任务标为中断。

失败/中断任务可 **重试任务**。选择模型/思考并确认后，回滚该轮题目、参考答案、试卷信息、生成图片及任务文件，替换为全新任务、日志、用量与授权。原件、先前结果和先前题目的笔记保留。既有费用和代码对任务目录外文件的修改不能撤销。

同卷正在处理、已有更新轮次、旧任务无恢复记录、或已存题目被编辑时拒绝重试。此时在试卷中 **重新识别**，保留当前结果与编辑。两种操作均可能产生新费用。

## 代码执行策略

| 设置 | 行为 |
| --- | --- |
| 每次询问 | 查看确切 Python/PowerShell 后在本机运行，允许后续调用仅对本任务有效，稍后保持等待。 |
| 沙箱运行 | Python 使用任务专属 AppContainer，PowerShell 每次独立 AppContainer，访问输入副本与专属结果目录，网络默认关闭。 |
| 直接在本机运行 | 当前默认，使用 Windows 账户文件和网络权限，不逐次询问。 |

启动前更改设置。沙箱不可用时，启动框说明拟用本机执行；正常沙箱中的失败不静默改用本机。供应商上传独立于沙箱网络。

Python 在任务内跨调用保留状态，普通异常不清空；超时、取消、输出超限、工作进程退出会重置。PowerShell 共享文件，不共享变量。生成图片可预览并复用于题目和 PDF。

## 本地诊断

Debug/Release 均写入 `%LOCALAPPDATA%/OhMyStudy/logs/session-<timestamp>-<pid>.log`，可用 `OHMYSTUDY_LOG_FILE` 指定文件。失败记录请求/工具参数、供应商拒绝正文、流中断位置、完整异常链；密钥、授权、Cookie、秘密 token 脱敏。日志可能含学习文字与代码，分享前检查，不自动上传。

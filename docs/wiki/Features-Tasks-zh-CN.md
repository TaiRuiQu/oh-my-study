# 任务进度、重试与执行请求

## 阅读任务活动

同一时间运行一个试卷任务，其内部各题可并行。启动后自动进入任务页，按“形式判断、上传与识别、切题与材料绑定、并行解答、作答评分”显示状态与产物数量。形式判断显示识别出的试卷形式与置信度；空白卷、参考答案导入等被跳过的阶段会明确标注“无需处理”。摘要显示已识别页数、已切出题目与模型费用估算，估算不含 OCR 和未定价调用。不同题目的解答与评分可能同时进行。

逐题列表分别显示解答与评分状态，包括等待、处理中和无需处理；作答匹配失败或评分无法确定的题目显示“待核对”。空白卷跳过评分，参考答案导入跳过解题和评分。“技术详情与模型记录”默认折叠，展开可查看模型回复、受控 Python 计算、输出与错误；旧 agent 对话不再作为主要任务界面。任务结束后可“导出识别材料”，保存包含 full.md、图片、OCR 记录、切题计划及已有模型结果的 ZIP。

在“设置 → 试卷识别与批改”从已有供应商选择切题与可选评分模型，启动框也可修改这些模型，并选择解题供应商与模型。直接复用供应商的地址和密钥，选择会被记住，每个任务保留自己的快照。模型调用失败后不会自动重放。

## 取消、重试或重新识别

取消停止后续操作并保留已存结果。最小化继续运行，退出停止；重启后未完成任务标为中断。

失败或中断任务可 **重试任务**。选择工作流模型并确认后，回滚该轮题目、参考答案、试卷信息、生成图片及任务文件，再启动全新工作流。保留原件、先前结果和受保护的手动修改，既有费用无法退回。

同卷正在处理、已有更新轮次、旧任务无恢复记录、或已存题目被编辑时拒绝重试。此时在试卷中 **重新识别**，保留当前结果与编辑。两种操作均可能产生新费用。

## 代码执行策略

| 设置 | 行为 |
| --- | --- |
| 每次询问 | 运行前审阅 Python 计算，允许后续调用仅对本任务有效。 |
| 沙箱运行 | 在任务专属 Python AppContainer 中运行受控计算器。 |
| 直接在本机运行 | 在本机运行受控计算器，不逐次询问。 |

启动前更改设置。沙箱不可用时，启动框说明拟用本机执行；正常沙箱中的失败不静默改用本机。供应商上传独立于沙箱网络。

仅解题阶段提供 Python 计算器，只接受允许的数学表达式和简单赋值，不提供 shell、导入、文件或网络操作，每次计算变量独立。思考与模型能力选项收纳在启动框的“模型与计算选项”。

## 本地诊断

Debug/Release 均写入 `%LOCALAPPDATA%/OhMyStudy/logs/session-<timestamp>-<pid>.log`，可用 `OHMYSTUDY_LOG_FILE` 指定文件。失败记录请求/工具参数、供应商拒绝正文、流中断位置、完整异常链；密钥、授权、Cookie、秘密 token 脱敏。日志可能含学习文字与代码，分享前检查，不自动上传。

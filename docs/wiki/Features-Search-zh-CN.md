# 文字与语义搜索

[首页](Home-zh-CN.md) · [功能详解](Feature-Guide-zh-CN.md) · [English](Features-Search.md)

## 本地文字搜索

在题库或错题中按题目文字、答案、笔记、试卷名搜索，结合学科/结果筛选和排序，滚动继续加载。文字搜索不调用模型。

## 配置语义搜索

打开 **设置 → 题意搜索模型**，分别配置向量与可选重排模型的 API 类型、基础地址、模型名和可选密钥。**OpenAI 兼容** 使用兼容服务的向量/重排契约；**DashScope** 使用原生接口，基础地址须按区域和工作空间以 `/api/v1` 结尾，应用自动追加操作路径。保存搜索模型，地址与模型同时留空可停用该模型。

连接独立于识别供应商。密钥存于 Windows 凭据管理器；密钥留空保留旧值，除非勾选移除已保存密钥。

## 搜索并核对上传范围

选择 **按题意**，描述概念，点击搜索或按 Enter。学科/结果筛选先于检索。确认向量服务地址、模型、新增或变化文字数量；每次搜索都会发送查询。配置重排时最多发送 50 个候选题目文字。搜索费用不包含在识别任务估算中。

索引包含题干、公式、评分项内容、选项、知识点，每题最多 6,000 字符，排除原件、个人笔记和学生答案。向量缓存于资料库，本地精确余弦相似度最多返回 50 题，可选远端重排。修改查询或筛选后需再次搜索刷新排名。

配置向量模型后，识别保存自动排队后台索引，识别确认框说明上传范围，仅发送新增或变化题目文字。停用向量模型后停止后台上传。后台失败不使识别失败，后续搜索可重试；取消保留已完成向量。

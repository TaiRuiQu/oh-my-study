## 处理第一份试卷

1. **安装。** 从[发布版本](https://github.com/TaiRuiQu/oh-my-study/releases)下载 Windows 10/11 x64 包。不确定时选择 `vX-aot` 发布。运行 `Setup.exe` 进行当前用户安装，或完整解压便携 ZIP 后打开 `OhMyStudy.App.exe`。其他版本与依赖说明见[安装指南](../installation.zh-CN.md)。
2. **配置模型。** 打开 **设置 → 添加供应商**，填写 API 类型、地址和密钥并保存。使用 **导入模型** 或 **添加模型**，确认图片、工具能力和思考选项，再 **保存模型**。测试连接会发送简短请求，可能计费。
3. **导入。** 点击 **导入试卷**，选择 PDF、PNG、JPEG 或 WebP，选择自动识别或指定类型及模型，再点击 **导入并识别**。试卷连同补充学生作答、参考答案最多 12 页。
4. **查看进度。** 在 **任务** 中查看页面读取、题目保存、执行请求和预估费用。题目会随保存逐步出现；原件已复制不代表识别完成。
5. **核对。** 打开试卷，使用 **查看原件** 和 **定位原件**，检查题目、答案、分数与公式。通过 **编辑题目** 修正并保存。
6. **复习与导出。** 在 **错题** 中复习错误，或在 **题库** 中浏览所有已保存题目。**导出题目** 会导出当前显示的已保存题目，可分别生成题目卷或答案解析册，选择 A4 或 A3 横向后保存 PDF。

AI 处理会将页面图片和任务上下文（包括相关已保存题目与参考答案）发送给所选供应商，可能产生费用。首次任务前检查 **设置 → 执行 → 代码与命令**：当前默认使用 Windows 账户权限直接执行模型请求的代码。需要逐次检查时选择 **每次询问**，需要 AppContainer 隔离时选择 **沙箱运行**。

## 所有功能速览

| 功能 | 用途 |
| --- | --- |
| 供应商与模型 | 添加、编辑、删除连接和模型配置；导入模型 ID 或手动添加。 |
| 模型参考信息 | 从 models.dev 填充，核对能力与价格后保存。 |
| 测试连接 | 导入前用简短请求检查已保存模型。 |
| 空白试卷 | 提取题目，不评分；空白答案不会变成错题。 |
| 已作答，需批改 | 提取学生作答，请求批改和解析。 |
| 已有教师批改 | 提取教师结果，补充缺失分析。 |
| 试卷列表 | 搜索、筛选，按日期/标题/学科/得分率排序并打开试卷。 |
| 试卷信息 | 修正标题、学科和总分信息。 |
| 原件阅读 | 对照来源页，翻页、缩放、适应页面、旋转或定位来源。 |
| 管理页面 | 调整页序、旋转，移除未被引用的页面。 |
| 编辑题目 | 修改文字、LaTeX 公式、表格、原件配图区域、选项、答案、解析、分值、评分、知识点与小问。 |
| 题库 | 浏览从试卷保存的题目。 |
| 错题 | 复习部分正确、错误、未作答的题目，也包含小问中的错误。 |
| 参考答案 | 添加答案页，再使用 **更多 → 整理参考答案**；此操作本身不会重新评分。 |
| 整理结果 | 检查答案匹配、待确认原因和逐页覆盖结果，跳转到答案原页。 |
| 重新识别 | 修正配置或补充参考答案后重新处理整卷；新调用可能计费。 |
| 任务 | 查看进度与日志、进入已保存题目、取消任务或回到最新日志。 |
| 执行请求 | 在询问模式允许或拒绝代码，可仅为当前任务允许后续调用。 |
| 用量与费用明细 | 查看 token 用量和预估费用；缺失数据不代表零费用。 |
| PDF 导出 | 分别导出题目卷或答案解析册，支持 A4 纵向、A3 横向。 |
| 资料库位置 | 打开文件夹、复制并切换位置，或选择已有的当前版本资料库。 |
| 备份与恢复 | 退出后复制完整资料库；恢复时保留备份并打开其副本。 |
| 删除试卷 | 确认后删除试卷、关联题目、参考答案、任务与库内原件。 |
| 外观 | 跟随系统、浅色或深色；语言可选跟随系统、简中、英语、日语或韩语，切换语言后重启。 |
| 键盘操作 | Ctrl+O 导入、Ctrl+S 保存、Ctrl+E 编辑题目、Ctrl+0 适应页面、Ctrl+1–4 切换分区。 |

## 完成前检查

打开 **整理结果**，核查无法识别的页面和未匹配答案。另行检查待确认判定，它们不会自动进入错题集。导出或切换资料库前保存修改。打印前检查 PDF，尤其是公式、配图裁片和分页。

具体步骤、限制与恢复方法见[功能详解](Feature-Guide-zh-CN.md)。

## 搜索与恢复

题库/错题支持本地文字搜索、筛选和独立阅读页，可切换上一题/下一题、逐项查看答案并保存笔记。接受向量/重排及明确上传范围时可配置[语义搜索](Features-Search-zh-CN.md)。

失败/中断任务可 **重试任务**，确认回滚本轮后重来；需保留现有结果或编辑题目时在试卷中 **重新识别**。见[恢复规则](Features-Tasks-zh-CN.md)。

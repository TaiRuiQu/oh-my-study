# 题目结构、评分约束与保留规则

[首页](Home-zh-CN.md) · [技术内幕](Tech-for-nerds-zh-CN.md) · [English](Tech-Validation-Grading.md)

## 公共题干与有序评分项

`Question` 保存稳定 `draft_key`、原题号、公共 `stem`、来源区域、学科/题型、知识点、待确认内容、笔记和有序 `items`。每个 `QuestionItem` 独立保存稳定 `key`、印刷标签、题目内容、选项、满分、标准答案、解析和可选作答。没有小问的题目仍有一个评分项，通常标签和内容为空，完整题目文字放在公共题干。

每题包含 1–100 个评分项。印刷上的嵌套标签展平为 `(2)(a)` 等形式，当前格式不再使用递归 `Parts` 树。多个评分项时标签不能为空。评分项键在整卷唯一；页面覆盖引用顶层题目键，参考答案匹配评分项键。

文字、公式、表格、图片仍为独立类型块。图片可引用处理后的 `asset_id`，同时保留原件来源区域。工具区域使用未旋转整页上 0–999 的整数 `bbox=[left,top,right,bottom]`；存储仍用归一化 `x/y/width/height`，由运行器转换。

## 写入前校验

封闭工具 schema 拒绝额外字段，类型反序列化检查结构，领域和仓储校验检查所有权与含义。题号、题干、材料页来源必填；稳定键最多 128 个 UTF-8 字节；单题序列化内容最多 1 MiB。

| 输入 | 结果 |
| --- | --- |
| 部分正确，2/4 分 | 分数与判定一致。 |
| 部分正确，4/4 分 | 拒绝；部分正确必须严格介于零分与满分。 |
| 待确认，实得 0 分 | 拒绝；待确认实得分必须未知。 |
| 满分未知但实得分确定 | 拒绝。 |
| 空白模式评分项包含作答 | 拒绝；不生成未作答评分。 |
| 参考答案来源为材料页 | 拒绝；参考证据须来自参考页。 |

全部评分项满分已知时才合计题目满分；全部评分项实得分已知时才合计实得分。不存在独立可编辑的父题评分或父子分数合计。

## 证据与受保护修改

作答分离学生答案、教师批注、参考匹配、AI 解答/分歧和评分。来源为 `Teacher`、`AiReference`、`AiSolution` 或 `Manual`。已有手动评分受保护，教师模式与自动识别模式还保留明确教师结果与证据。AI 不能创建手动来源或移除受保护评分项。

标准答案与解法分别保存在评分项的 `answer`、`explanation`，空白卷也生成，但不创建作答。旧字段 `attempt.ai_solution` 保持可读。可空的 `attempt.error_analysis` 单独说明错误或部分正确作答中有证据支持的错因，与评分理由分开。

补充作答页使用 `role=student`。工具通过 `attempt.student_page_ids` 提交证据，转换为整页来源区域；题目本身仍须引用材料页。匹配复用已有评分项键。`SaveStudentAnswersAsync` 将修改的作答标记为手动录入，清除过期评分证据并设置待确认判定；空白模式转为自动识别，试卷实得分清空。AI 保留录入文字，同时可更新未受保护的评分字段。

`ConfirmQuestionAsync` 清除题目的 `uncertainties`，保留笔记与评分，要求试卷空闲，不会把待确认判定变成已解决的判定。

重新识别复用稳定键。省略附加字段保留旧值，显式空值可替换未受保护内容。个人笔记在识别后保留，但题目文字没有完整版本历史。

## 完成与集合规则

`finish` 检查必需页面各出现一次、已完整读取、来源键有效、参考答案匹配有效评分项。整卷任务须在本次保存全部现有顶层题。仅整理参考答案的任务覆盖参考页，不能保存题目或试卷信息。

任一评分项部分正确、错误或未作答，整题进入错题。评分待确认或抄录有疑点时进入待确认；只有不确定性不代表已确定错误。完成只校验一致性，不能保证每个符号与评分正确。

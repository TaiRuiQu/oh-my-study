## 先找失败阶段

按启动 → 本地导入 → 供应商请求 → 工具保存 → 最终覆盖 → 本地导出的顺序定位。重装不能修无效密钥，反复改模型 ID 不能补本地文档组件。

| 证据 | 排查 |
| --- | --- |
| 任务前启动失败 | 完整包、依赖、Windows/CPU 兼容。 |
| 导入失败 | 格式、加密/损坏、页数/字节/像素。 |
| 供应商失败 | 协议/地址、密钥、ID、额度、网络、思考/能力。 |
| 任务等待 | 选中任务、许可请求、供应商活动。 |
| 保存工具失败 | 必填、来源角色/范围、分数、稳定键/引用。 |
| finish 失败 | 未整页读、遗漏题、覆盖或匹配无效。 |
| 导出失败 | 草稿、手写标记、来源图、预算、工具、目标。 |

先读错误和最后活动，诊断时保留原件与结果。质量问题需人工比证据，不能把重试当保证。

## 无费用不等于免费

查单价、货币与桶数量，供应商可能漏统计。缺失与明确零不同，实际收费看供应商用量/账单。

## 外观与语言

外观可跟随 Windows、浅色、深色。语言支持简中、英、日、韩及跟随系统，切换保存后重启。不支持的系统语言回退英语，中文区域用简中。

这是界面翻译，不翻译原题、用户文字、旧响应。生成解析当前要求简中，日/韩界面不增加对应打印字体，需检查输出。

## 重试保留什么

取消、失败、中断保留成功提交。重识别可更新非保护字段；结构化手动评分和教师模式明确教师结果受保护，但后一次运行不是完整还原机制。

## 提交有效问题

提供版本、包类型、Windows、输入类型/页数、模式/协议、步骤、状态、错误，说明能否用小型非私人样例复现。公开材料需遮密钥、身份、学生笔迹和私密内容，优先最小样例而非整库上传。

## Files API 与恢复诊断

Responses 上传拒绝 `purpose=vision` 表明使用旧构建，当前推理上传已使用 DeepSeek 要求的 `user_data`。更新后重试任务。供应商须支持图片文件 ID 和一小时过期契约，否则在新任务前关闭支持 Files API，并接受内联图片请求大小限制。

已启用该选项但供应商仍提示 multipart 缺少 `purpose` 或过期字段时，请升级到 v0.1.9 或更新版本，使用修正后的字段格式。工具参数格式错误现在会在任务内反馈模型修正；反复失败时仍需查看任务和本地日志定位原因。

重试任务在恢复/编辑检查允许时回滚本轮，重新识别保留现有结果。见[恢复与本地日志位置](Features-Tasks-zh-CN.md)。失败日志包含详细信息及可能的私密学习文字，分享前检查。

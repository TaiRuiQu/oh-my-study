# 4. 制作复习资料并保护资料库

[首页](Home-zh-CN.md) · [快速开始](Quick-Start-zh-CN.md) · [English](Quick-Start-Review-Export.md)

![PDF 版式：A4 纵向与 A3 横向双栏，题目版和答案版分别导出。](images/pdf-layouts.png)

## 选择适合本次复习的集合

打开试卷可集中复习整卷；题库查看全部已存题；错题包含部分正确、错误、未作答。任一小问错误也会让顶层题收录。错题由已存判定生成，不是独立收藏清单。

导出前检查当前列表并保存草稿。导出框数量是关键：包含当前显示的已存题，而非只选中一行。

## 生成两个文件

先选题目，使用 A4 纵向或 A3 横向；再重复导出答案与解析。用可区分名称，例如“代数复习-题目.pdf”和“代数复习-答案.pdf”。

题目卷默认紧凑排版；可勾选“加入答题空白”为主观题留作答区，再按需勾选“均分页面剩余空白”扩展这些区域。答案版使用标准答案和解析，不使用学生作答代替。A3 横向默认双栏，栏数可单独选择。每页页眉提供班级、姓名和学号填写栏。上图仅示意布局，不是精确打印预览。

## 打印前检查

用阅读器打开两个 PDF，核对公式、裁图、题号、小问和分页。公式源码警告意味着需检查相应记法。含手写配图应先换为真正干净的来源区域；改标记不会擦笔迹。

导出本地完成。重识别是独立、可能计费的模型操作，仅换纸型无需重跑识别。

## 独立备份

在设置 → 资料库确认实际路径，保存、退出后将完整目录复制到其他位置。PDF 是复习输出，不能代替可编辑资料库。

恢复当前版本资料时保留备份，制作工作副本，再选择副本为已有资料库。换电脑可能需重填密钥。复制并切换位置会保留原库，但同一故障磁盘上的副本不是独立备份。

# 2. 导入并识别第一份试卷

[首页](Home-zh-CN.md) · [快速开始](Quick-Start-zh-CN.md) · [English](Quick-Start-First-Exam.md)

![学习流程：模型设置、本地导入、识别、对照原件、题目集合和 PDF 导出。](images/study-workflow.png)

## 准备少量、可读的样本

使用 PDF、PNG、JPEG 或 WebP，先确认能打开，题号、配图和笔迹可辨。试卷含补充学生作答和参考答案最多 12 页，单个源文件最多 64 MiB，单批 256 MiB，单张图不超过 4,000 万像素。

首次选择你能自己核对的材料。少量空白试卷适合学习识别，少量已作答试卷可体验评分。

## 选对模式

| 材料 | 模式 | 预期 |
| --- | --- | --- |
| 让模型自行判断 | 自动识别 | 模型阅读页面后按下述对应模式处理。 |
| 只有题目，没有学生作答 | 空白试卷 | 结构化题目、标准答案与解法，不创建评分作答。 |
| 有学生作答，需要评价 | 已作答，需批改 | 学生答案与 AI 批改。 |
| 教师已经批阅 | 已有教师批改 | 教师证据，保护明确教师结果。 |

不要为了让空练习进入错题而选已作答模式。空白模式刻意不把未填写题目算错。

## 开始处理

先打开“设置 → 试卷识别与批改”，沿用已保存的 MinerU Bearer Token，从已有供应商中选择切题模型（如 DeepSeek `deepseek-flash`），直接复用供应商的地址与密钥。可选另一评分模型，启动框也可分别选择本次切题、解题和评分模型；默认并行 3 题，每题最多 4 次解题调用。准备好的内置 YOLO 检测器在本机运行，中文 ONNX 权重应独立核验后再配置。

页面发送给 MinerU 和切题模型，绑定题目发送给解题模型，原始作答截图发送给评分模型。显示的费用估算不包含 OCR 及未配置单价的模型费用。

点击导入试卷，选文件、试卷类型、供应商、模型并核对思考选项。上一次的供应商、模型和思考选择会被记住。未确认其他选项受支持时先用默认。模型能力未确认时，了解不确定性后再允许尝试。

设置页使用相连的图标 Steps，各阶段旁边就是对应配置；启动框用横向流程条展示“形式判断、上传与识别、切题与材料绑定、并行解答、作答评分”。思考和计算权限放在“模型与计算选项”。点击“启动工作流”后，本地保存原件、任务排队，并自动打开任务页；导入成功后，外部源文件不再是唯一副本。

## 观察首次结果

OCR 运行后，待任务结束，可在任务详情点击“导出识别材料”，保存包含 `full.md`、页面图片、原始 OCR 和流水线结果的 ZIP。

任务页展示五步进度，包括识别出的试卷形式、已识别页数、已切出题目，以及逐题解答和评分状态。空白试卷明确显示无需评分，被跳过的阶段会直接标注；模型输出、计算和错误可在“技术详情与模型记录”中展开查看。题目可能先于整项任务完成出现；原件已保存只证明导入，不证明整卷已识别。

任务失败时保留试卷，阅读错误并修正模型或材料问题；用重试任务回滚失败轮次后重来，或重新识别以保留现有结果，详见[任务恢复](Features-Tasks-zh-CN.md)。新调用可能计费，但可避免无谓重复导入。

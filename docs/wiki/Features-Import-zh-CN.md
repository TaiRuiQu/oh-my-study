# 导入模式、限制与原件页面管理

![学习流程：模型设置、本地导入、识别、对照原件、题目集合和 PDF 导出。](images/study-workflow.png)

## 上传前准备

先自行打开，解密加密 PDF，检查页序、小字、笔迹。支持 PDF、PNG、JPEG、WebP；不支持的办公文档应先在原应用转换。

限制分层：试卷、学生作答附件与参考共 12 页、单文件 64 MiB、批次 256 MiB、图片 4,000 万像素，派生图片也有处理预算。小 PDF 仍可能超页数，单页图仍可能超尺寸。

## 直接使用手机拍照

在“导入试卷”“添加参考答案”或“上传学生作答”中选择“手机拍照”。手机与电脑连接同一 Wi-Fi，用手机相机扫描电脑显示的二维码，即可直接进入拍摄页面，无需安装 App、登录、输入 IP 或配对码，也可以复制连接链接。

每次拍摄一页，也可以选择已有图片或 PDF。批量选择多张照片后会依次检查，发送一张后自动打开下一张；页面显示已接收和待上传数量。某张失败会保留待处理队列，可以重试或跳过后继续。应用在本地检测照片中的页面边缘、四角和文字方向，方向明确时会自动转正横拍或倒拍的照片。检查并拖动四角，或选择“保留整张照片”，也可点击“向右旋转”手动调整方向，然后预览透视矫正效果。支持彩色修复、灰度修复、不增强；确认文字没有被裁掉后发送此页，继续拍摄下一页。文件按拍摄顺序排列，可以在手机上移除；刷新手机页面后，也可以继续编辑已上传但尚未发送的照片，尚未上传的文件需要重新选择。完成后在电脑上点击“导入”，继续原有的识别设置与确认流程。拍摄原图和矫正后的页面会分别保存在资料库中。

临时接收服务只监听选中的电脑网络。二维码包含随机会话凭据，有效期为 20 分钟，关闭窗口即停止接收。照片通过局域网 HTTP 传输，请仅在可信网络使用。拍摄处理使用随包附带的本地 CPU 模型：DocAligner LCNet100 检测四角，PaddleOCR PP-LCNet_x1_0_doc_ori 判断方向，DocScanner-L 进行稠密展平，权重合计约 45.7 MB，无需云中转、供应商密钥、显卡或模型 API 调用。四角置信度不足时会保留整张照片，供手动调整。现有页数、单文件和批次限制仍然适用，原图与处理后的图片都计入预算。多个 PDF 即使文件数少于 12，也可能超过页数限制，最终导入时会验证实际页数。

若扫码后无法连接，可在上传前切换电脑网络，保持电脑唤醒；若 Windows 提示，请允许 Oh My Study 在专用网络上通信。访客 Wi-Fi 可能隔离设备，也可以使用手机热点将两台设备接入同一网络。部分扫码内置浏览器限制拍摄，可在 Safari 或 Chrome 中打开链接。修复可以改善轻微书页弯曲与失焦，但无法重建缺失细节；严重模糊、反光或折叠页面应重新拍摄。

## 模式是评分契约

自动识别由模型根据页面图片和已保存作答判断空白、已作答或已有教师批改，再按对应规则处理。已明确材料类型时可指定模式。

空白模式提取题目并生成标准答案与解法，不创建学生作答，即使有参考答案。已作答模式保留作答并区分实际空白与无法辨认。教师模式优先明确教师结果，未知部分才用 AI。对于错误或部分正确的作答，模型在证据充分时单独报告错因分析，无法判断时留空。

导入后，在试卷中使用“更多 → 上传学生作答”添加作答照片或 PDF，也可以在题目页通过“录入学生作答”输入单题的作答过程，再重新识别试卷。新增作答匹配已有题目键，保留原题与标准解法。空白卷补充作答后切换为自动判断，以便模型批改。手动录入作答受到保护，修改作答会清除旧评分和错因分析。

模型也可以报告试卷上可见的标题；没有标题时保留导入名称，重新识别不会覆盖用户手动修改的标题。

例如红笔扣分符号缺少上下文时，不应凭空变成数值评分。满分未知不能捏造得分。参考答案用于证据匹配，不允许覆盖明确教师结果。

## 本地文档修复

手机照片先按手动页角和旋转进行裁切，再使用内置、可在 CPU 上运行的 DocScanner-L 稠密反向网格模型展平弯曲页面。彩色与灰度修复随后通过 OpenCV 进行基于亮度的去阴影，以及保守的 Richardson–Lucy 反卷积，恢复轻微失焦。**不增强**仍保留几何校正，但跳过这些光度处理。取消或重新调整预览时，原件与手动页角不会丢失。严重运动模糊、反光及缺失细节仍应重新拍摄；发送前务必检查浅色铅笔笔迹与数学内容。

只有当单张 NVIDIA 独立显卡的专用显存严格大于 12 GiB，且已安装的 CUDA 运行时能初始化同一物理设备时，电脑端手机导入窗口才允许安装可选 **DocRes**。恰好 12 GiB 不符合要求；多卡显存不相加。驱动版本提示、CUDA 目录或共享内存都不能代替运行时验证。主动点击电脑端的**下载并安装 DocRes**后，才下载总计 896,242,296 字节（约 855 MiB）的模型权重，以及另需数 GB 的独立 Python/PyTorch CUDA 运行时。下载进度写入日志，可取消安装，启动应用不会自动下载。安装通过校验值及实际 CUDA FP32/FP16 推理自检后才就绪；还需单独启用，随后在手机端选择 DocRes。上述处理均在本机执行，不向供应商上传照片。

展平、去阴影、去模糊与外观增强可分别勾选，按展平→去阴影→去模糊→外观增强的顺序执行。选择 DocRes 展平时不会再执行 DocScanner 展平；仅选择 DocRes 光度任务时，仍由 DocScanner 负责几何校正。**不增强**也会跳过神经网络光度任务。外观增强可能改变浅色笔迹，应先检查预览。大图去模糊采用重叠的 768 像素块与渐变拼接；去阴影和外观增强遵循上游 1600 像素限制，并用比例图恢复原始细节。CUDA 显存不足或模型失败后仍可编辑页面，选择**标准（DocScanner + OpenCV）**后重试；取消处理不会确认或替换页面。

DocRes 下载单独保存在 `%LOCALAPPDATA%/OhMyStudy/DocRes`。关闭启用选项后停止使用，但不删除已下载文件。需要兼容的 NVIDIA 驱动和已安装且可用的 CUDA 运行时，应用不会安装全局 CUDA 工具包。

DocScanner 作者为 Hao Feng，使用单独的非商业许可证，要求署名和相同方式共享；商业用途必须提前取得作者书面许可。内置 ONNX 模型将上游 U2NETP 掩码与 12 次迭代 DocScanner-L 组合，并输出归一化反向网格。许可证与修改说明随软件提供在 `native/scanner/DocScanner-LICENSE.md` 和 `DocScanner-NOTICE.txt`。DocRes 使用 MIT 许可证。开发准备方法见[安装说明](../installation.zh-CN.md)。

## 保存什么

导入复制原件到受管理资源，准备本地页图/缩略图，识别另行执行。外部文件断开不影响库内副本，但删除试卷会删除该副本。

PDF 页面保留原资源与原页号关系。旋转/排序写为元数据，不改写外部 PDF。

## 导入后管理页面

打开试卷 → 更多 → 管理页面，上下移动或左右旋转，检查后保存。只能删除未引用页，至少留一页。

引用包括题目来源、配图、学生区域、教师证据、小问、答案来源。被阻止时应检查该页用途，绕过会破坏定位。更改结构前结束处理任务。

## 识别没有完成

查看任务，不反复导入。原件已存与任务失败/取消可同时成立，修正错误后重识别，保留已有成果。源材料确有缺陷时获取更清晰副本，并在替换或重处理前安排编辑保护。

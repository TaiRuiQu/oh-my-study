# Oh My Study 实现计划

状态：架构定稿对应的执行计划，已开始 M0 风险验证。实际完成项、验证证据与交接顺序统一维护在仓库根目录 [progress.md](../progress.md)；本文的通过条件不代表已经验收。

## 1. 开发顺序

先验证本地执行、三种协议和正式试卷排版，再完成“导入批改 → 题库错题 → 复习卷”闭环，最后完善手机传图与离线分发。阶段按依赖顺序推进，不把所有功能一次性搭成大系统。

| 阶段 | 交付 | 依赖 | 通过条件 |
| --- | --- | --- | --- |
| M0 风险验证 | 三种权限模式、Windows Sandbox 桥接、协议往返、公式到 PDF、资源测量 | 已定稿需求与选型 | 技术路径成立，主要风险有可操作的处理方式 |
| M1 应用基础 | React 桌面界面、SQLite、资产管理、任务列表、供应商／模型设置 | M0 | Windows 可启动，配置、数据、任务事件正常 |
| M2 整卷闭环 | 图片／PDF 导入、整卷识别批改、参考答案、自动入库、编辑 | M1 | 三份样卷覆盖输入与结果流程，无静默漏页和跨题串答 |
| M3 题库与错题 | 标签合并、筛选、最近 N 天选题、错误结果联动 | M2 | 日常查询与维护可用，操作简单一致 |
| M4 复习卷 | 原题复现、AI 新题与校验、Matplotlib 图形、打印 PDF | M2–M3 | 生成题目卷／答案册，A3 双栏实际打印可读 |
| M5 发布完善 | 手机扫码传图、备份恢复、性能、离线包、说明文档 | M4 | 干净 Windows 环境可离线安装，核心闭环验收通过 |

只实现整卷入口，不开发独立单题入口或单题 Agent。

## 2. M0：优先验证三个关键路径

### 执行环境

1. 准备应用私有 CPython 与固定版本的 NumPy、SymPy、Pillow、Matplotlib，不借用开发电脑现有环境。
2. 实现 Windows Sandbox 能力状态检测、默认选择和不可用时警告／本机绕过权限，准确显示有效模式。
3. 用 .wsb、LogonCommand 和文件桥接跑通 Windows 10／11，不依赖新版 CLI 进程 I/O；验证映射权限与沙箱关闭。
4. 实现请求权限的逐次批准、允许本任务和拒绝；宿主绕过权限不增加文件／网络拦截，不自动提权。
5. 绘制含中文和数学标签的几何图、函数图，验证只读运行时、缓存可写位置、SVG／PNG 和中文路径。
6. 验证超时、取消、进程树／本应用所有沙箱的结束与内存释放；不会接管或关闭用户已有的 Windows Sandbox。
7. 验证不支持、未启用、虚拟化关闭、重启待完成、已有会话及启动失败；不可把宿主执行显示成沙箱。沙箱中断不自动在宿主重放未知是否已执行的命令。

详细矩阵与默认值见 [执行与权限设计](execution-permissions.zh-CN.md)。Windows Sandbox 桌面窗口和启动开销单独验证，不能保证它表现得像普通隐藏子进程。

### 原生协议

每种协议实现一次“文本＋图片 → 工具调用 → 工具结果＋图片 → 完成”的往返，再启用模型相应的思考配置。测试正常和流式响应，不把三种协议套入同一个请求 JSON。

覆盖分页模型列表、手动模型 ID、未知能力、参数不支持、429、认证失败和取消。保留 thinking／reasoning／signature 的必要原始上下文。

先用协议录制样本验证解析与状态；真实调用需使用用户自行配置的密钥，记录所选模型、配置与用量。没有真实调用时不能把 mock 通过写成供应商已验收。

### 正式试卷排版

使用自建题目验证：分式、矩阵、上下标、中文公式、化学反应式、选项表格、结构图与长小问。WebView 生成自包含公式 SVG，Typst 排出 A3 双栏和 A4 单栏。

重点检查 SVG 基线、字体、行高、分页、栏末图表、续题、留白及答案册。预览与导出使用同一份 PDF。此阶段发现渲染路径问题时先修正选型，不把格式转换缺陷留到最后。

### 资源基线

记录空窗口、打开题库、查看大页、宿主 Python、Windows Sandbox、生成 PDF 各阶段的内存和磁盘占用。沙箱初始配置 2048 MB，分别报告宿主、虚拟机和相关系统开销；不要求沙箱模式遵守原来的 1 GiB 合计目标。离线包不再以 200 MiB 为硬上限，分别报告应用、计算环境、字体、PDF 引擎、WebView2 和系统沙箱组件的实际大小。

## 3. M1：应用基础与前端设计

- 初始化 Tauri 2 + React + Vite + TypeScript，Rust 独立业务模块，配置格式化、lint 和类型检查。
- 建立视觉规范：字号、间距、按钮、输入框、列表、状态、对话框与空态；先完成导入页、题目详情、模型设置和 PDF 预览的连贯界面。
- 首版以桌面单窗口为主，适配常见笔记本分辨率和 Windows 125%／150% 缩放。
- SQLite 初始化、迁移、外键、参数化查询、WAL、专用数据库工作线程。
- 资产导入、原件保留、类型探测、缩略图、缓存与安全文件引用。
- 供应商协议、地址、密钥引用、模型列表、思考能力和价格配置。
- Rust 任务队列、Tauri 进度通道、取消和统一错误展示。
- 三种权限选择、沙箱状态、实际执行环境标记、请求权限弹窗和 WAITING_PERMISSION 状态。

验收：应用使用本地静态资源，启动不依赖模型供应商可用；数据库、图片和设置操作不会阻塞界面；密钥不通过前端状态、日志、普通备份或计算子进程环境传递。沙箱不映射密钥或数据库，宿主模式如实展示其当前用户权限，不虚称隔离。

## 4. M2：整卷识别与批改

- 支持 JPG／JPEG、PNG、WebP 和 PDF；扩展格式按实际样本增加，不依靠用户文件后缀判断类型。
- 一批对应一份材料，支持排序、旋转、删除页、附加参考答案；默认最多 12 个输入页，更多材料由用户分批处理。
- 导入模式分为已有教师批改、待 AI 批改、空白试卷。已有教师结果优先提取，未标注题由 AI 判断并标明来源，不用 AI 覆盖已明确的教师结果。
- 在原图像素和 PDF 页之间保留稳定引用；模型按需查看原页或裁片，不固定两栏或逐题派生 Agent。
- 为已作答整卷、空白卷、参考答案整理设置独立业务指令；只有整卷入口，不开发单题 Agent。
- 题目结构支持小问、选项、材料、图片、表格、分值、标准答案、解析和知识点。
- 批改分离“学生作答”“教师已有批改”“参考答案”“AI 自行解题判断”；教师模式以教师明确结果为准，AI 评分时冲突仍按参考答案评分。
- 自动保存题目与结果，重复工具调用仅在本任务范围内保证幂等，不合并不同导入。
- 无法识别的部分保留原图与原因，不制造确定分数；空白试卷不制造未作答记录。
- 批改详情支持对照原图、修改内容和重新批改；不做修改历史。

参考答案允许同时导入或后补。建议后补后展示已匹配关系，再由用户点击重新批改，避免自动产生新的模型费用。

验收：三份样卷全部页进入覆盖检查；数学三栏与生物续题不因版式变化被静默丢弃；化学卷优先提取教师批改，AI 补充结果来源清楚；得分和小问总分一致，缺失和不确定内容有明确标记。

## 5. M3：题库、错题与知识点

- 完整题库与错题作为同一数据的不同视图，不复制维护两份题目。
- 错题包括错误、部分正确、未作答；未作答同时显示两个标记。
- 按学科、知识点、日期、题型、来源筛选，支持文字搜索和分页。
- AI 引用已有标签 ID；支持人工编辑、重命名、合并与关联同步。
- 最近 1 / 7 / 30 天和自定义天数，显示明确日期范围，以本地日历日计算。
- 原始作答日期缺失时默认使用入库日期，不把试卷印刷年份当作作答日期。
- 跨学科自动选题默认分学科建卷；不引入掌握状态、间隔复习或学习提醒。

验收：标签合并后查询和题目详情同步；手动改分后错题视图立即更新；日期边界正确；重复导入仍得到独立题目；真正无法判定的题不进入默认选题结果。

## 6. M4：巩固卷与复现卷

### 原题复现

按选择结果创建卷子内容快照，去除学生作答及答案，保留必要的原题图。题图带笔迹时保留标记，用户可替换图片或编辑正文。重扫后的结果按新材料处理。

### AI 巩固

用户选择错题范围、学科、题数、难度、题型和模型／思考选项。Agent 可查询分页错题与标签，自主安排覆盖，生成新题、答案和解析，使用 Matplotlib 绘图。

独立上下文先解题，再比较结果；不通过的题返回生成任务修正。设置修正次数上限，仍不通过则保留草稿和原因。有效题数不足时不能标成完成，不自动塞入原题替代新题。

### 打印

实现 A3 横向双栏、A4 纵向单栏，正式试卷题型标题、选项布局、页码、字体、题序、答题留白和分页控制。按真实试卷习惯显示大题分值或必要的解答题分值，不在每题统一贴分值。

分别保存题目卷和答案解析 PDF，内置预览，支持导出后交由系统打印。没有 Word 导出或自由拖拽版面编辑。

验收：所有题号、参考答案和解析对应；原作答不混入题目卷；纸面无裁切、重叠、公式缺字或不合理缩图；A3 100% 打印的字号和留白可用。

## 7. M5：手机、备份、资源与发布

- 手机传图：用户开启时启动临时接收端，生成带随机会话凭证的二维码；手机网页只能上传当前会话，不暴露题库、密钥或命令接口。
- 对手机文件设置单文件、总量与像素限制，确认接收后进入普通导入流程，完成后关闭监听。
- 备份：一致数据库快照、原件／图形／PDF 与清单打包；不包含密钥。恢复前校验版本、哈希和引用完整性。
- 完整离线包：应用、CPython、固定 wheels 内容、字体、PDFium、排版资源和必要的 WebView2 离线安装组件。
- Windows Sandbox 是系统可选功能，不重新分发系统镜像。提供启用说明，本轮不自动修改系统；功能不可用不阻碍本机模式安装和使用。
- 在无 Node／Python／TeX 的干净 Windows 10 / 11 x64 环境安装；离线验证启动、材料预览、计算和排版，再联网测试模型。
- 统计应用及其相关进程的私有内存，并单列沙箱 VM 与系统开销。以真实 12 页材料、重复打开关闭页面、连续任务、取消任务和 PDF 生成检查峰值与泄漏。
- 为所有实际分发组件生成许可证声明与组件清单；公开仓库不包含用户样卷、作答或密钥。
- 提供用户手册、供应商设置、计算环境说明、数据目录、备份恢复、更新和卸载说明。

首版手动下载更新，无独立常驻更新器；后续再按需求加入签名自动更新。发布安装包时同步可获得的对应源码、锁文件、构建说明与第三方声明。

## 8. 拟定代码结构

```text
src/
  app/                  # 导航、窗口布局、主题
  features/
    import/             # 文件与参考答案入口
    grading/            # 原图对照与批改
    questions/          # 题库、编辑、来源
    wrong-questions/    # 错题筛选与时间范围
    papers/             # 组卷设置、PDF 预览
    settings/           # 供应商、模型、思考与费用
  components/           # 通用组件
  lib/                  # IPC、数学 SVG、格式化
src-tauri/
  src/
    commands/           # Tauri 边界
    domain/             # 题目、作答、标签、卷子
    storage/            # SQLite、资产、备份
    jobs/               # 队列、取消、进度
    ai/
      providers/        # 三种原生适配器
      agents/           # 业务任务指令和完成条件
      tools/            # 图片、标签、保存
    execution/          # Python、命令、平台策略
      sandbox/          # .wsb、会话所有权、文件桥接、guest runner
      host/             # 当前用户 Python／命令执行
      permissions/      # 请求权限、批准绑定、有效模式与警告
    documents/          # PDF 输入、内容与排版
    phone/              # 临时接收端
  migrations/
  resources/            # 固定模板、字体、运行时清单
runtime/                # 计算环境构建来源与锁定说明
docs/
```

先用模块边界保持清楚，不预先拆成大量独立 crate、服务或进程。

## 9. 必要验证

| 类别 | 验证内容 |
| --- | --- |
| Rust 业务 | 分值、小问合计、错题过滤、日期范围、标签合并、保存幂等、取消后的迟到写入 |
| 协议 | 三种流式事件、工具往返、图片、思考上下文、用量、错误与不支持参数 |
| 数据 | 数据迁移、一致备份恢复、资产引用、损坏输入、清理不误删原件 |
| 执行 | 三种模式、沙箱就绪／不可用／占用、桥接、逐次批准、不自动提权、超时、会话／子进程所有权、中文路径、Matplotlib |
| 排版 | A3／A4 真实尺寸、公式基线、化学式、图表、分页、题答对应及打印 |
| AI 样例 | 人工标注题目／小问／作答归属与评分依据，分别记录识别、评分、知识点、生成题错误 |
| 桌面端到端 | 导入、批改、编辑、错题筛选、组卷、导出、手机上传与备份恢复 |

确定性业务和协议解析做自动化验证；样卷识别与语义评分需要实际模型和人工基准，不用 mock 通过替代准确率报告。不为简单静态界面或本文档另外编写形式化测试。

## 10. 发布前仍需实测的项目

- 完整离线安装包与安装后磁盘占用。
- 空闲、识别、绘图、排版时全进程私有内存，以及沙箱 VM／系统开销。
- 冷启动至可操作时间，以及题库规模上升后的搜索响应。
- 不同供应商／模型的任务完成率、识别遗漏、批改差异、调用次数与费用。
- 长题、作文和英语写作的上下文长度与可用评分标准。

这些是实现后的验证工作，不把尚未运行的结果写成已经达标。当前不设置未经样本支持的“识别准确率 99%”等承诺。

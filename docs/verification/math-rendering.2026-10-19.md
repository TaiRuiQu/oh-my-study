# 公式显示与切题渲染验收

2026-10-19，本地源码修复与 Native AOT 验证完成，尚未提交、制作安装包或发布。本轮仅使用隔离示例资料库，没有读取真实试卷、凭据或请求模型。

## 实现结果

- 题目正文、选项、表格、小题与批改反馈共用公式排版。相邻文字和公式按原文顺序组成段落，行内公式保留共同基线；`$$…$$`、`\[…\]` 独立成段，`$…$`、`\(…\)` 保持行内语义。保留显式换行，处理转义与相邻公式，未闭合或不支持的内容保留可读原文。
- 使用实际 Typst 字形矢量，移除 PDF 光栅化、逐像素着色与 PNG 再编码链路。兼容 WinUI 支持的 SVG 字形组，显式提供渲染尺寸，并随主题与窗口 DPI 更新；正文采用 12pt 非衬线字体，数学字母采用 sans 样式。打印正文仍使用已有的新宋体配置。
- 补充 `\mid`、`\boldsymbol`、`\bm`、`\mathsf`，正确区分 `\mathbf` 与粗斜体，以及 `\dfrac` 与 `\tfrac`。按真实字形上下边界排版，修复大分式分母、根号等在段落边缘被裁切的问题。
- 每种正文宽度一次批量编译，排版与可复用图像分别采用有上限的缓存，工具哈希只在后台校验一次。快速切换取消过时请求，旧题不会覆盖新题；尺寸变化合并后重排。长独立公式保持字号并提供可聚焦的横向滚动，正文继续按窗口宽度换行；表格单元格按内容收缩。公式段落支持右键复制原文，普通文字保留原生选择。

# VelociTex 1.0.0-preview6 升级验收

2026-10-20。按用户指定版本，将 VelociTex.Core、VelociTex.Rendering.Direct2D、VelociTex.WinUI 从 1.0.0-rc.2 切换为 1.0.0-preview6。只使用 nuget.org，不依赖相邻源码或本地包源。旧验收记录保持原样。

## 变更

- 更新中央版本及普通、AOT、自带运行时、依赖运行时依赖锁；锁文件由 NuGet 实际还原生成，包含 preview6 的内容哈希与原生运行时资源。
- preview6 新增 VelociTex.Core.Native.dll；离线包检查将其列为必需文件。公式调用接口兼容，本轮无需改动题目、预览和打印呈现代码。
- 保留随包原始字体和全部许可证；界面正文仍为非衬线字体，打印正文仍为系统新宋体。
- 架构及应用 README 更新至当前版本。

## 验证

- 整解决方案 Release 构建及 CI Checks 通过，0 警告、0 错误。Checks 覆盖四种发行配置、Debug / 非 AOT 及文档探针和媒体测试双模式锁定还原。
- CI Lint、git diff --check 通过。
- 媒体回归 26 项通过；本轮媒体程序使用 JIT 运行，不记作 Native AOT。
- App 与文档探针 Release Native AOT 发布通过，无编译、裁剪或 AOT 警告。文档报告确认 DynamicCodeSupported=false；发布物中的新核心 DLL 与 NuGet 原始字节一致，三个包的许可证、通知及 KaTeX 声明均与上游哈希一致。
- 新发布应用的 --math-smoke、--preview-smoke 均通过。覆盖实际正文/公式基线、100/125/150/200% 表面密度重建、段落与单式原文复制、UIA 原文、取消、超宽公式滚动至末尾、实时主题、反馈段落、500 行复用、缓存和快速切换。表面密度重建不等同于真实多屏 DPI 验收。
- 文档探针通过：8 类实际 SVG 字形路径、中文、矩阵、分段函数、cancel/boxed、错误和取消、所有题干/选项/表格/答案/解析/小问公式路径，以及 A3/A4、题答隔离、519 个表格单元格、12 层小问、超长原文回退。

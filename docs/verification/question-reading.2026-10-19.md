# 题目预览与选项排版复查

2026-10-19。对左侧题目摘要、正文与选项字体差异、选项中的公式继续修复。此记录接续 `math-rendering.2026-10-19.md`；旧记录保留当时构建的事实，不作为本次最终版本的证据。验证仅使用隔离示例资料库，没有读取真实试卷或凭据、调用模型、提交或发布安装包。

## 修复范围

- 左侧摘要采用真实字形排版，文本、公式与表格摘要保留内容顺序。分式、根式、矩阵、分段函数不会被粗暴裁切；两行内按完整数学单元省略，省略号与前文保持在同一行。超宽且不可拆分的数学单元省略，不缩成细小字体。单行摘要按实际高度收缩，避免固定高度造成空白。
- 正文、分值和选项使用同一套 12pt 非衬线字形与矢量呈现；摘要为 10.5pt。选项中的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`、裸 `\frac`/`\dfrac`、上下标和中英文混合表达均经过相同边界处理。识别仅作用于显示，保存的原文不改写。普通中文选项不误判为数学表达。
- 补充 Unicode 希腊字母、转义集合大括号、百分号/美元符号、`\frac12`、局部 `\displaystyle`/`\textstyle`。未闭合或不支持的输入在详情保留原文；摘要使用简短失败状态，不暴露残缺命令。空题目、仅公式、长公式、表格和图片标题均有摘要入口。
- 保留列表虚拟化，按可见区域和少量缓冲安排预览批次；取消屏外或已过时的排版，复用条目先核对当前题目身份。已缓存正文直接命中，不等待后台摘要编译。字形与图像缓存均按数量和估算字节限制，图像缓存计入像素缓冲。
- 预览图像不接管点击，行点击仍由题目列表处理。窄窗口采用上下布局，调整布局后保持选中行可见。主题和缩放改变时重新取色、栅格化；深色模式调整宽度后创建的新正文也从当前控件主题解析文字颜色。

## 实际截图验收

最终构建与报告索引见 `question-reading.2026-10-19.json`。截图由运行中的应用等待布局和呈现任务稳定后，通过 `RenderTargetBitmap` 自动产生；未使用 Computer Use 进行布局验收。检查整张实际截图及关键原尺寸截图，包含文字清晰度、字体一致性、基线、分母/根号边缘、换行、省略、对齐、行高、主题对比、列表选中状态及答案/备注相邻区域。

预览场景使用 19 类题目，并另建 500 道内容各不相同的题目。覆盖 1440×960、900×850、720×960、460×960 窗口以及深浅主题。

| 范围 | 截图后缀 |
| --- | --- |
| 左侧列表、普通中文选项、含公式选项 | `list`、`plain-options`、`math-options` |
| 深色、侧栏收起的中等窗口、上下布局、紧凑窗口 | `dark`、`medium-dark`、`narrow-dark`、`compact` |
| 矩阵、失败回退、底部复杂公式和表格摘要 | `matrix`、`unsupported`、`bottom`、`bottom-dark` |
| 单个长公式、空资料库 | `single-formula`、`empty` |
| 500 题顶部/中部/底部及快速往返滚动 | `large-top`、`large-middle`、`large-bottom`、`recycled` |

同时复查公式阅读的 16 个截图场景，覆盖分式/根式、四种分隔符、表格/小题、超长正文与可横向滚动的独立公式、失败回退、普通文字、快速切题。之前发现的固定预览高度、摘要垂直居中、孤立省略号、窄窗选中行隐藏、预览抢占行点击和深色新正文取色问题均修复后重跑。

测试曾把 WinUI 放在屏外等待复用的已加载条目也当作可见项，导致错误失败。这些条目实际位于列表上方数百至数万像素；已改为按真实可见范围检查，并要求连续两次可见条目和对应呈现任务稳定。复用检查同时核对矢量源存在及图像内容对应当前题目。没有将屏外未排版条目伪装成可见缺图，也未放宽可见条目的完整检查。

为防止深色回归，额外读取实际正文图像的渲染像素，确认每个图像含有可见的浅色字形；该检查覆盖首次切换主题以及不同窗口宽度后新建正文。

## 结果与边界

最终运行结果和本机性能样本随报告索引记录。首次场景总耗时包含等待和自动截图；dispatcher 样本在排版结束后采集，不能作为高负载帧时间指标。缓存切题测量包含选择处理与布局，不等于 GPU 呈现时间；没有把不同样本的冷启动时间换算成严格加速倍数。

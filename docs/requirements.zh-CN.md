# Oh My Study 需求与决策记录

更新：2026-10-18。本文记录当前产品约定；需求不代表全部功能已经实现。实际状态见 [维护进度](../migration-progress.md)，技术实现见 [架构](architecture.zh-CN.md)。

待办：完整标签与高级筛选、按日期选错题、复习卷生成与独立校验、手机传图。现有固定模板 PDF 导出不代表复习卷功能完成。权限默认值也须区分约定与现状：当前应用新设置默认绕过权限，自动优先选择沙箱尚未实现，详见 [执行与权限](execution-permissions.zh-CN.md#2-默认值与不可用处理)。

## 1. 产品范围

- 本地单学生桌面程序，面向初中及以上学习场景，明确包含 K12 教育。
- 学科和年级作为可编辑元数据，不把题库结构硬编码为九科；大学学科的专门验收范围尚未约定。
- 仅 Windows 10 / 11 x64，设备内存 8 GB 及以上；不投入 macOS / Linux 或跨平台界面适配。
- 核心功能：材料识别与批改、全题库和错题整理、知识点管理、错题复现卷与 AI 巩固卷。
- 产品文案遵守[技术细节上精简](design-principles.zh-CN.md)：只展示用户需要的内容、操作和结果；实现/测试/迁移说明留在维护文档，必要限制用普通语言准确提示。
- 数据本地保存；在线 AI 由用户自行配置供应商、API 地址、密钥和模型。
- 使用 C# + WinUI 3 + Fluent Design 2 原生界面，以 Release Native AOT 发布；采用原生控件、编译绑定与局部状态更新。
- C# 等价承担业务、数据、任务、网络和 Windows 能力编排。界面、公式、PDF 预览、导出及打印不依赖 WebView2、Edge、Chromium 或其他浏览器。
- 允许固定版本的 SQLite、PDFium、Typst 和按需启动的私有 Python；普通用户无需开发 SDK、系统 Node/Python/完整 TeX。
- 开源发布，项目选用 GPL-3.0-or-later，保留各依赖的原许可证与声明。

## 2. 材料入口与识别

- 导入图片、PDF，主要为已经作答的试卷与练习册；也支持空白试卷、参考答案。
- 手机传图接受同一局域网扫码、使用手机浏览器上传，无需手机 App；可作为核心功能后的版本。
- 暂不需要扫描仪直连、电脑摄像头采集或自动拆分多份试卷。
- 一批对应一份试卷／练习，常见为 4 张 A3 图片，或 8–12 张 A4 图片；最大日常输入为 12 张图片，约对应六面 A3。
- 整卷交由整卷 Agent 自主处理，不按单题创建 Agent；按页读取和裁图不等于拆分成单题 Agent。
- 只保留整卷入口，取消独立单题入口和单题 Agent。
- 作文、英语写作、证明题、实验题、材料分析等均在批改范围内。
- 支持手写、公式、表格、配图与跨栏／跨页的题目、小问和作答。不能固定假设输入只有两栏。
- 尽可能识别所有题目；对不确定内容继续尝试并明确标注，不因不确定直接跳过。
- 真正无法识别的内容仍保留原图与标注，默认不进入错题列表或复习卷；不额外增加复杂审核流程。
- 题干与学生作答分离；接受保留含笔迹的题图并标注，不要求自动去除笔迹。

## 3. 批改与保存

- 没有参考答案时，AI 自行解题并批改。
- 导入区分“已有教师批改”“待 AI 批改”“空白试卷”三种模式。
- 已有教师批改的材料主要提取教师对错与评分，AI 补充解析；AI 异议单独展示，不覆盖教师结果。
- 教师没有明确对错或评分标记的题，由 AI 补充判断，明确标记来源为 AI。
- 输出对错、部分正确、得分、逐步解析、错误原因和知识点。
- 由 AI 批改时，参考答案与 AI 判断冲突则展示冲突与 AI 判断，评分仍依照参考答案；提取已有教师批改时以教师结果为准。
- 原题没有分值时允许估算，展示估算标记。
- 已作答材料中的空白题计入错题，同时标记“错题”和“未作答”。
- 空白试卷导入属于题库录入，不因没有作答而自动制造未作答／错题记录。
- 保存识别出的全部题目及作答记录，自动入库；重复导入不用合并题目。
- 允许修改题干、选项、配图、作答、参考答案、解析、评分与知识点，不需要修改历史。
- 已打印复习卷做完后可重新导入并批改，按普通新材料处理，不需要原卷关联、重复题合并或特殊复习追踪。

## 4. 标签与错题

- 知识点由 AI 自动生成，生成时先参考已有标签，避免语义重复。
- 支持标签改名、合并，并同步关联题目。
- 错题列表展示题目与知识点，支持筛选。
- 默认按学科隔离知识点；部分正确计入错题；不额外做掌握状态、复习提醒和归档状态机。
- 支持按最近 N 天的错题自动选题，提供 1 / 7 / 30 天及自定义天数。

## 5. 两种复习卷

- 错题复现卷：使用原错题，隐藏学生原作答、答案及解析，重新编排。
- AI 巩固卷：基于错题和知识点生成新题，可设置题数、难度和题型，默认接近原题难度。
- 巩固题生成后进行独立解题校验，失败则修正或重新生成；校验不代表数学正确性的绝对保证。
- 支持生成几何图、函数图等代码能够绘制的图；实验图可采用文字描述或联网寻找，不要求生成实验装置图。
- 主要打印后在纸上作答，不开发软件内作答系统。
- 支持 A3 双栏与 A4 模板、PDF 导出；不需要 Word 导出。
- 允许调整字号、题序、答题留白和分页；不做自由拖拽排版。
- 卷面按真实试卷组织，不要求每题显示分值；分值优先放在大题／题型说明，必要时显示解答题总分。
- 题目卷与参考答案解析分开。

## 6. 模型供应商与思考配置

- 原生支持 OpenAI Responses、Anthropic Messages、Google Gemini Generate Content 三种协议。
- 用户提到的 Gemini 文本生成接口按 generateContent / streamGenerateContent 实现，不替换成其他协议。
- 每个供应商有独立模型列表；用户可选择任意已配置模型，并在实际任务中设置该模型支持的思考选项。
- 不把所有供应商、模型的思考参数强行合并成固定的“低／中／高”三档。
- 支持默认模型及任务覆盖；支持刷新供应商模型列表、缓存列表与手动添加模型。
- 模型是否支持视觉、工具调用和思考强度分别记录；能加入列表不等于拥有所有能力。
- 显示任务用量与费用；费用需要按配置单价估算，缺少单价不能显示为免费。

## 7. Agent 与本地执行

- 尽量使用自主 Agent，简单功能可只调用一次 API。
- Agent 可自由编写、执行 Python 和命令，使用 Matplotlib 等完成绘图与计算。
- 保留常用工具：读取图片、放大／裁图、旋转、查询已有标签，以及必要的结果保存。
- 不单独开发专用几何绘图、函数绘图或计算工具，这些交给 Python。
- 权限模式为“请求权限”“沙箱运行（支持时可用）”“绕过权限”。
- 支持且已就绪的电脑默认用 Windows Sandbox 执行 Python 与命令，不使用 AppContainer 代替 Windows Sandbox。
- 不支持或不可用时允许在宿主机执行，不额外施加应用层文件／网络权限限制，并警告用户、明确显示实际模式。
- 请求权限模式在宿主机执行，每次 Python／命令调用前展示代码／命令并请求允许；可仅允许本次或本任务，拒绝则不执行。
- 绕过权限模式不弹出逐次确认，在当前 Windows 用户权限内执行，不自动提升管理员权限。
- 沙箱默认关闭网络，只映射所需运行时、输入和通信／输出目录；模型网络请求由宿主 C# 执行。网络开关作为沙箱高级设置。
- 权限模式和有效执行环境在任务开始时确定并展示；不可把失败后在宿主运行的任务显示为沙箱运行。
- 一次只运行一个 AI 任务，其余排队；取消／失败保留已成功保存的结果。
- 最小化时继续运行；退出时停止。用户不需要托盘常驻或完整断点续作。

## 8. 安装、存储与资源

- 提供完整离线安装包，包含 Python 计算依赖；接受整体磁盘占用超过原先 200 MiB 目标。
- 离线指安装、字体、排版和计算依赖不必联网安装；AI 功能仍按已确认方式调用在线模型。
- 不安装或依赖系统 Node.js、完整 TeX、Docker、WSL 才能使用程序。
- 原件本地保存，预览与处理中间缓存可重建、可清理；手动完整备份／恢复作为简单默认方案。
- 空闲应用私有字节目标 150 MiB、首轮门槛 200 MiB；本机常规任务应用及所属辅助进程总私有字节约 1 GiB，包含本机 Python 子进程。Sandbox 开销单列。
- Windows Sandbox 初始配置 2048 MB 内存；整体资源占用含虚拟机单独测量，不承诺沙箱加宿主峰值仍低于 1 GiB。
- 完整离线包不重新分发 Windows Sandbox 系统组件。Windows 功能启用、系统安装源、更新或重启属于操作系统准备步骤；功能不可用不阻止本机模式使用。
- 上述数字为验收目标；已有本机采样和未达标项见 [维护进度](../migration-progress.md)，参考设备验收尚未完成。

## 9. 已采用的简单默认值

- UI 使用 WinUI 3 与 Fluent Design 2，统一导航、按钮、输入、对话框、状态与主题资源，验证键盘、焦点、中文输入法、读屏、DPI、多显示器与减少动画。
- 参考答案补传后由用户点击触发重新批改，不自动产生新模型费用。
- 默认整卷处理，不开发独立单题入口、线上答题、修改历史或特殊复习追踪。
- 权限行为与 Windows Sandbox 的版本兼容方案见 [执行与权限设计](execution-permissions.zh-CN.md)。
- 其余实现细节由开发方依照简单、轻量的目标决定，已记录于架构与维护进度；不把尚未实测的结果描述为达标。

## Exam titles

- Rename imported exams from the exam list's context menu by choosing **Exam details**, or edit them while the exam is open.
- Preserve subject and score metadata, protect manually edited titles during later recognition, and keep list and detail views synchronized.

## Velopack installation and incremental updates

- Replace MSI, MSP, WiX, and the legacy custom installer with Velopack one-click `Setup.exe` packages.
- Check for updates under **Settings → About**, confirm the download, then restart after saving unfinished work.
- Publish `aot`, `self-contained`, and `framework-dependent` builds as independent releases and update channels. Subsequent releases include full and delta packages; Velopack falls back to the full package when a delta cannot be used.
- Keep portable ZIP downloads, with manual full-package upgrades for portable installations.
- Remove the AVX-512 build and use the portable x86-64 AOT target.

## Upgrade

Back up the library, uninstall the old MSI-based app through Windows **Installed apps**, then install the new `Setup.exe`. Study materials, credentials, and settings remain outside Velopack's installation directory. This first Velopack release contains full packages only; subsequent releases provide delta packages. See [installation](../installation.md).

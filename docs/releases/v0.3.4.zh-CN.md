# v0.3.4

[English](v0.3.4.md) · [安装指南](../installation.zh-CN.md)

## 修复增量更新

- 修复更新下载成功、重启后仍为旧版本，且更新日志报 `Missing required manifest property: mainExe` 的问题。
- 将依赖包元数据保留为 `.nuspec.xml`，确保增量包重建后更新器始终读取应用清单。
- 发布前校验全量包、增量包和重建包的应用标识、版本、更新通道及可执行文件。新增使用原生 Windows 更新器的回归测试，覆盖从旧元数据文件名的安装包升级。

## 安装排障

如果 Setup 无法替换已有应用目录，请关闭应用，以及正在使用安装目录的编辑器和终端，再重试。如果用 Sublime Text 打开过安装目录中的文件，请完全退出 Sublime Text；其崩溃报告辅助进程可能占用目录。日志位置和恢复步骤见[安装指南](../installation.zh-CN.md)。

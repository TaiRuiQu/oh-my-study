## 试卷标题

- 在试卷列表右键菜单中选择“试卷信息”即可重命名导入的试卷，也可在打开试卷后编辑。
- 保留学科和分数信息，重新识别时保护手动修改的标题，并同步列表与详情视图。

## Velopack 安装与增量更新

- 使用 Velopack 一键 `Setup.exe` 替代 MSI、MSP、WiX 和旧自定义安装器。
- 在“设置 → 关于”中检查更新，确认下载，保存未完成工作后重启安装。
- `aot`、`self-contained` 和 `framework-dependent` 分别使用独立 Release 和更新通道。后续 Release 提供全量包和差分包，差分不可用时自动回退到全量包。
- 保留便携 ZIP；便携版仍需手动下载并完整替换程序文件。
- 移除 AVX-512 构建，普通 AOT 使用可移植的 x86-64 目标。

## 升级

先备份资料库，通过 Windows“已安装的应用”卸载旧 MSI 版，再运行新的 `Setup.exe`。学习资料、凭据和设置均独立于 Velopack 安装目录。首个 Velopack Release 仅提供全量包，后续 Release 提供差分包。详见[安装指南](../installation.zh-CN.md)。

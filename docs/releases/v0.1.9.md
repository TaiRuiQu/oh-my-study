# v0.1.9

[简体中文](v0.1.9.zh-CN.md) · [Documentation](../wiki/Home.md)

## Student answers and grading

- Import with automatic exam-type detection or an explicit blank, answered, or teacher-graded mode. The last provider, model, and reasoning choice are remembered.
- Generate standard answers and solutions for blank exams. Recognition can use the exam's printed title while preserving manually edited paper information.
- Add answer photos/PDFs with **More → Upload student answers**, or type work with **Enter student answer**, then **Recognize again**. Responses match existing items; manually entered work is preserved. Changing a response clears its previous assessment. The exam, answer attachments, and references share the 12-page limit.
- Show separate evidence-supported error analysis for incorrect or partial work, leaving unknown causes empty.
- Clear reviewed transcription concerns with **Confirm result** while retaining content, notes, and grades. An uncertain grade can still require review.

## Reading and provider fixes

- Restore the previous window size and maximized state. Wrap long formulas at suitable operators while preserving complete formula source when copying.
- Target 200 KiB per model image using PNG or color JPEG and bounded resizing. Library originals, reading previews, and PDF export assets retain their existing quality. The target can be exceeded to retain readability and does not guarantee lower image token charges.
- Correct multipart Files API field formatting and return malformed tool arguments to the model for correction instead of executing them or immediately terminating the task. Uploaded files retain the one-hour expiration and cleanup policy.
- Refresh the English and Chinese README, installation, usage, prompt-profile, and repository Wiki guides against the implementation.

## Upgrade

This version upgrades writable libraries to SQLite schema **v6** for supplementary student-answer pages. Save, close the app, and back up the **entire library folder** before first launch. The automatic `study.sqlite3.pre-v6-…` snapshot contains the database only; older apps cannot open upgraded libraries. Existing page IDs, order, rotations, and original-PDF relationships are preserved.

Four Windows x64 variants provide MSI and portable ZIP packages: `aot`, `aot-avx512`, `self-contained`, and `framework-dependent`. Choose ordinary `aot` if unsure. See [installation](../installation.md) and [student work and review](../wiki/Features-Workspace-Editing.md).

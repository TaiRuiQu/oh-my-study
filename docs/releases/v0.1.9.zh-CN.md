## 学生作答与批改

- 导入时可自动识别试卷类型，也可指定空白、待批改或已有教师批改模式。记住上次使用的供应商、模型和推理选项。
- 为空白卷生成标准答案与解法；识别可采用试卷印刷标题，保留手动修改的试卷信息。
- 通过 **更多 → 上传学生作答** 补充照片/PDF，或通过 **录入学生作答** 输入作答，再 **重新识别**。作答匹配已有评分项，保留手动录入的文字；修改作答会清除旧评估。试卷、补充作答与参考答案合计最多 12 页。
- 对错误或部分正确的作答显示有证据支持的独立错因分析，原因不明时留空。
- 对已核查的识别疑点点击 **确认结果**，清除待确认文字，保留内容、笔记与评分；待确认评分仍可能需要核查。

## 阅读与供应商修复

- 恢复上次窗口尺寸和最大化状态；长公式在合适运算符处换行，复制仍保留完整公式源码。
- 发给模型的图片以每张 200 KiB 为目标，使用 PNG 或彩色 JPEG 并限制缩放。资料库原件、阅读预览和 PDF 导出资源保留现有质量；为保留可读性仍可能超出目标，也不保证图片 token 费用降低。
- 修正 Files API multipart 字段格式；工具参数格式错误时反馈模型修正，不执行错误参数或立即终止任务。上传文件仍采用一小时过期和任务结束清理策略。
- 按实现同步更新中英文 README、安装指南、使用指南、提示配置与仓库内 Wiki。

## 升级

本版本会将可写资料库升级到 SQLite **v6**，用于保存补充学生作答页面。首次启动前请保存、退出，并备份 **整个资料库目录**。自动生成的 `study.sqlite3.pre-v6-…` 快照只含数据库，旧版应用无法打开升级后的资料库。原页面 ID、顺序、旋转和原始 PDF 关联保持不变。

四种 Windows x64 构建均提供 MSI 和便携 ZIP：`aot`、`aot-avx512`、`self-contained`、`framework-dependent`。不确定时选择普通 `aot`。详见[安装指南](../installation.zh-CN.md)与[补充作答及核查](../wiki/Features-Workspace-Editing-zh-CN.md)。

# v0.3.5

## Frosted window background

- Use native Desktop Acrylic for the title bar, navigation, and workspace background while keeping question and document surfaces readable.
- Let Windows fall back to a solid background for insufficient graphics hardware, Battery Saver, high contrast, or disabled transparency effects.
- Fix saving and restoring window size and maximized state in Native AOT builds by explicitly projecting the WinRT window presenter.

## Recognition improvements

- Accept common model argument variations for grades, grading sources, text answer options, and student working without discarding unknown content or bypassing score and reference validation.
- Repeat all available tool parameter schemas in a fixed developer message for providers with Codex mode enabled.
- Allow reasonable estimates of unprinted question and subquestion points using common scoring conventions and known totals. Record estimated allocations and their basis in question uncertainties; identify dependent AI scores in grading reasons. Preserve printed teacher scores and protected manual grades.

# v0.3.14

[English](v0.3.14.md) · [安装说明](../installation.zh-CN.md)

## 本地图像矫正

- 使用项目微调的几何矫正与白底增强 ONNX 模型，替换 DocRes 和旧文档矫正流程。
- 保留几何矫正前的自动方向识别。几何模型接收完整照片，不做四角裁剪或透视预处理。
- 电脑图片导入新增默认关闭的**使用图像矫正**选项，覆盖参考答案、学生答案及拖放导入。
- 手机端可分别开关方向识别、几何矫正和白底增强；手动旋转优先于自动转正。
- 原图与处理后的 PNG 分开保留，PDF 不做矫正。
- 随应用分发模型及许可证，通过 ONNX Runtime 在 CPU 本地推理，无需另装 Python、CUDA 或模型。

## 整卷得分

- 没有明确整卷得分时，在所有已保存题目均有确定得分后累加各题分数。
- 保留显式分数，包括手动填写的分数。缺失题目得分仍视为未确定，计算出的总分不会覆盖模型原始输出。

## 验证与限制

- 锁定依赖的 Release 还原、Release 编译及 Native AOT 发布成功；Release 编译为零警告、零错误。
- 已用提供的照片目视检查实际 C# 方向识别、几何矫正与白底增强输出。本轮尚未对新的导入确认弹窗和手机相机／局域网流程做交互验收。
- 未运行测试、Lint 或性能基准。几何输出保留转正后原图的宽高比，本流程不提供模型去模糊。

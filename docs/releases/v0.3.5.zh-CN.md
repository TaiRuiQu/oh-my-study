# v0.3.5

[English](v0.3.5.md) · [安装指南](../installation.zh-CN.md)

## 磨砂窗口背景

- 标题栏、导航区和工作区背景使用 Windows 原生 Desktop Acrylic 磨砂效果，题目与文档阅读区域保持清晰。
- 硬件支持不足、开启省电或高对比度、关闭系统透明效果时，由 Windows 自动降级为纯色背景。
- 使用 WinRT 显式转换获取窗口控制器，修复 Native AOT 版本无法保存、恢复窗口尺寸和最大化状态的问题。

## 识别改进

- 兼容模型在评分字段、评分来源、文本选项和学生解题过程上的常见参数写法，继续拒绝会丢失内容或违反分数、引用约束的调用。
- 为开启 Codex 模式的供应商，在固定的 developer message 中重复全部可用工具的完整参数 schema。
- 题目或小问未印分值时，允许根据常见配分方式和已知总分合理估算，在识别疑点中说明估算分配与依据，并在评分理由中标明依赖估算分值的 AI 得分。保留已印教师分数和受保护的人工评分。

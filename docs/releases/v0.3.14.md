# v0.3.14

[简体中文](v0.3.14.zh-CN.md) · [Installation guide](../installation.md)

## Local image correction

- Replace DocRes and the previous document-correction pipeline with the project's fine-tuned geometry and white-background ONNX models.
- Retain automatic orientation before geometry correction. The geometry model receives the complete photograph without corner cropping or perspective preprocessing.
- Offer an initially unchecked **Use image correction** option for computer image imports, including reference answers, student answers and drag-and-drop.
- Provide independent orientation, geometry and white-background switches on the phone. Manual rotation takes precedence over automatic orientation.
- Keep original images separately from corrected PNGs. PDFs remain unchanged.
- Bundle model weights and license notices. Correction uses ONNX Runtime CPU without a separate Python, CUDA or model installation.

## Paper scores

- When no explicit whole-paper score exists, sum question scores once every saved question has a determined score.
- Preserve explicit scores, including manually entered scores. Missing question scores remain undetermined, and the calculated total does not overwrite model output.

## Verification and limits

- Locked Release restore, Release build and Native AOT publication succeeded. The Release build reported zero warnings and zero errors.
- Visually inspected the actual C# orientation, geometry and white-background output on a supplied photo. The new import confirmation and phone camera/LAN flows have not received interactive verification in this integration.
- No tests, lints or performance benchmarks were run. Geometry retains the upright photograph's aspect ratio, and this pipeline does not provide learned deblurring.

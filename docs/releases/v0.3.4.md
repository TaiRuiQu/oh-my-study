# v0.3.4

[简体中文](v0.3.4.zh-CN.md) · [Installation guide](../installation.md)

## Incremental update repair

- Fix updates downloading successfully but restarting into the old version with `Missing required manifest property: mainExe` in the updater log.
- Preserve dependency package metadata as `.nuspec.xml` so the updater always selects the application manifest after rebuilding a delta package.
- Validate the application identity, version, channel, and executable in full, delta, and reconstructed packages before release. Add a regression test using the native Windows updater, including upgrades from packages with the old metadata filenames.

## Installation troubleshooting

If Setup cannot replace the existing application directory, close the app and any editors or terminals using its installation folder, then retry. Fully exit Sublime Text if it has opened files there; its crash-reporting helper can hold the directory open. See the [installation guide](../installation.md) for log locations and recovery steps.

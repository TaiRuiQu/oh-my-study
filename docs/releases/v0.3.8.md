## Exam PDF layout

- Print the sequential number, parenthesized score, and question stem together; remove the extra original-number paragraph.
- Use compact question spacing and consecutive parenthesized part numbers without blank lines between parts.
- Arrange four options in one row, two rows of two, or four rows of one using their rendered widths, including formulas.
- Add ruled Class, Name, and Student no. fields in the repeated page header.
- Add independent, default-off options for subjective answer space and even distribution of remaining page/column space. Choice and fill-in questions receive no extra writing area. Base heights use standard-answer length, line breaks, score, and column width; answers remain hidden on question papers.

## Build-only CI

- Remove all automated test projects, regression scripts, fixtures, document probes, and embedded smoke-test launch modes.
- CI compiles the application and creates the three distribution variants; it runs no lint or tests.
- Remove full-solution formatting lint and the workflow-linter download. Local lint only checks changed whitespace and has a hard 30-second limit.
- Review PDF and UI changes visually using realistic content.

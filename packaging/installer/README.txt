To use the installation wizard, double-click the MSI for the same version and choose the installation location and whether to create a desktop shortcut.
After extracting the portable ZIP, run OhMyStudy.App.exe directly.
You can uninstall from Windows Settings; study materials and backups are preserved.
If you have an old EXE installation, uninstall it first, then install the MSI.
